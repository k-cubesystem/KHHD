# 신당 음원 라이선스 대장 (CREDITS)

이 폴더의 음원 파일 출처·라이선스·확인일을 기록한다. **라이선스가 불확실한 파일은 절대 넣지 않는다.**
파일이 없으면 앱은 자동으로 오실레이터 합성음으로 폴백하므로, 수급과 무관하게 배포는 안전하다.

## 파일 규약 (`components/shrine/scene/useShrineAudio.ts`)

- **효과음(FX)**: `fx-{soundKey}.mp3` — soundKey ∈ `moktak`(목탁) · `chime`(풍경) · `bell`(종) · `water`(낙수) · `crackle`(촛불) · `bara`(바라)
  - 있으면 Web Audio 버퍼로 재생, 없으면 합성 폴백. 짧게(≤2초) 권장.
- **배경음(BGM)**: `bgm-{theme}.mp3` — theme ∈ `banga` · `choga` · `yonggung` · `dokkaebi`
  - 있으면 `HTMLAudioElement`(loop, 음량 0.25)로 재생, 없으면 절차 국악 앰비언트 폴백.

## 현재 상태 (2026-07-21, 세션26)

**수급 파일 0건 — 사용자 선곡 대기.**

- BGM(국립국악원 정악/산조 등)은 **트랙 선곡이 취향 영역**이라 사용자 선곡 대기가 기본.
- 효과음(CC0)은 freesound(다운로드에 OAuth 토큰 필요)·Pixabay(CDN)에서 자동 수급을 시도했으나,
  바이너리 다운로드가 로그인/도구 제약으로 막혀 **구조(폴백 포함)만 완성**했다.
- 파일을 이 폴더에 넣는 즉시 실음원으로 전환된다(코드 수정 불필요).
