# 스레드 계정 페르소나 — 「많이 본 사람」

작성 2026-08-21 · CEO 반려("페르소나가 딱 와닿지를 않아") 후 신설 · 상위 `TEAM_G_DESIGN/prd/PLAN-threads-marketing-v3.md`

## 0. 왜 흐릿했나

원고 25편과 도구를 만들면서 **말투(반말)와 세계관(지도·나침반)은 정했는데, 「말하는 사람」을 정하지 않았다.**
그래서 어떤 글은 상담가처럼, 어떤 글은 친구처럼, 어떤 글은 편집자처럼 말했다. 톤은 같은데 사람이 없었다.

---

## 1. 이 계정은 누구인가

> **몇 천 명 봐준 사람이, 아는 사람한테 말하듯.**

권위가 **신비에서 오지 않고 표본에서 온다**는 게 핵심이다. "기운이 흐르고 있습니다"가 아니라 **"이런 사람 많이 봤어"**.
그래서 반말이 성립한다 — 위에서 내려다보는 반말이 아니라, 많이 봐서 이미 아는 사람의 반말이다.

| 축          | 이 계정                              | 이 계정이 **아닌** 것         |
| ----------- | ------------------------------------ | ----------------------------- |
| 권위의 출처 | 봐온 사람 수 ("이런 사람 많이 봤어") | 신비·영험 ("기운이 보입니다") |
| 거리        | 아는 사람 (반말)                     | 선생님 (존댓말·훈계)          |
| 태도        | 찔리는 말을 하되 판단은 안 함        | 위로만 하거나, 겁을 줌        |
| 결론        | 방향만 짚고 물러남                   | "이렇게 살아라"               |
| 돈          | 값을 먼저 말하지 않음                | 굿·비방 영업                  |

## 2. 말버릇 (이게 곧 사람이다)

**쓴다**

- "이런 사람 많이 봤어" / "~한 사람이 왔어" — 표본에서 나오는 권위
- "그거 게으른 거 아니야" — 남이 붙인 딱지를 떼어주는 말. 이 계정이 제일 잘하는 것
- "~편이야" — 단정하지 않는 어미
- "그 뒤는 그 사람 몫이고" — 물러서는 자리
- 자기 얘기 ("나도 그랬어")

**안 쓴다**

- "제가 볼 때는" · "~하셔야 합니다" — 선생님 말투
- "기운이 흐르고" · "조상이" — 신비주의
- "큰일 납니다" · "지금 안 하면" — 겁
- "반드시" · "무조건" · "틀림없이" — 단정
- 한자 · 일간/십성/재성 같은 우리 용어

## 3. 이 사람이 세 가지 콘텐츠에서 어떻게 말하나

| 유형       | 이 사람의 위치                                                       |
| ---------- | -------------------------------------------------------------------- |
| 정보형     | **분류하는 사람** — "이 질문 들고 오는 사람들은 셋 중 하나야"        |
| 스토리형   | **본 사람** — "~한 사람이 왔어" (증인이지 주인공이 아니다)           |
| 사이다형   | **업계를 아는 사람** — 겁 파는 수법을 안에서 본 사람만 할 수 있는 말 |
| 인사이더형 | **알려주는 사람** — "저장해놔" (팔지 않고 알려준다)                  |
| 한줄형     | **매일 있는 사람** — 같은 시각에 항상 있는 것 자체가 이 사람의 성격  |

## 4. 도구(3초 사주)의 페르소나 — 유형 이름 규칙

🔴 **설명문이 아니라 부를 수 있는 이름.** 「책임지고 버티는 형」은 나를 *서술*하는 말이라 캡처해서 올릴 이유가 없었다.

- 형식: **「~하는 사람」** (「~형」 금지 — 테스트가 막는다)
- **찔리는 맛**이 있어야 한다. 좋은 말만 있으면 «내 얘기»가 안 된다
- 결점을 부르되 **마지막엔 편을 들어준다** — 겁주는 집과 갈리는 지점
- 16자 이내 · 열 개가 서로 안 겹칠 것

### 열 가지 (2026-08-21 확정)

| 이름                         | 설명 구절                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------ |
| 거절을 못 하는 사람          | 부탁이 유독 너한테 몰리지. 잘해서 그런 건데, 그게 너를 갉아먹는 것도 맞아      |
| 참다가 한 번에 터지는 사람   | 웬만하면 참아. 근데 한 번 터지면 관계가 끝나. 참은 게 아니라 미뤄둔 거였거든   |
| 가만히 못 두는 사람          | 돈이든 일이든 손에 들어오면 굴려야 직성이 풀려. 그래서 크게 벌고 크게 잃어     |
| 돈이 손에 안 붙는 사람       | 버는 게 문제가 아니야. 들어오는 길이 많은 만큼 나가는 길도 많은 거지           |
| 일단 벌이고 보는 사람        | 생각보다 몸이 먼저 나가. 수습은 늘 나중이지만, 벌인 만큼 진짜로 커지는 쪽이야  |
| 먼저 주고 나중에 서운한 사람 | 줄 땐 아무 생각 없다가 안 돌아오면 그때 아프지. 안 주면 되는데 그게 안 되고    |
| 아직 안 터진 사람            | 없는 게 아니라 아직 안 꺼낸 거야. 남들보다 반 박자 늦게 가는 게 네 속도고      |
| 보고 배워서 따라잡는 사람    | 먼저 시작한 사람을 어느새 앞질러 있어. 대신 처음부터 혼자 만드는 건 힘들어하고 |
| 다 내가 하고 마는 사람       | 맡기느니 내가 하는 게 빠르지. 그러다 혼자 남는 게 이 유형 결말이고             |
| 혼자 두면 시드는 사람        | 옆에 누가 있으면 두 배로 해. 누구랑 있느냐가 실력보다 큰 사람이야              |

> 「거절을 못 하는 사람」(남이 맡긴 걸 못 거절)과 「다 내가 하고 마는 사람」(남을 못 믿어 내가 함)은 **다른 사람**이다.
> 헷갈리면 열 개가 뭉개지므로 테스트로 고정했다.

## 5. 세 줄(돈·인연·때) 규칙

🔴 두루뭉술하면 «내 얘기»가 안 된다 — **겪어봤을 장면 하나**를 반드시 넣는다(25자 이상, 테스트로 고정).

| 이전 (반려)                                             | 지금                                                                                             |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 돈 자리가 비어 있는 편이야. 한 방보다 꾸준한 쪽이 맞고… | 돈 자리가 비었어. 큰돈 노리다 오히려 잃는 쪽이라, **안 쓰는 게 버는 거야. 재미없지만 그게 맞고** |
| 쌓은 만큼 나오는 편이야. 앞당기려고 서두르면…           | 쌓은 만큼 나와. **지름길 찾다가 한 바퀴 돌아온 적 있지?** 그게 네 패턴이야                       |
| 내가 먼저 챙기고 먼저 주는 편이야…                      | **네가 먼저 주고 먼저 연락해. 그러다 지치면 확 식는 것도 너고**                                  |
