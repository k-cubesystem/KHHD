## 1. 이름 — 「해담」

| 항목      | 값                     |
| --------- | ---------------------- |
| 표시 이름 | **해담 · 청담해화당**  |
| 아이디    | **@haedam.haehwadang** |

**왜 해담인가**

- **브랜드가 이름 안에 들어있다** — 해화당의 「해」 + 담다의 「담」. 사람 이름인데 브랜드가 안 지워진다
- **성별·나이대가 안 드러난다**(CEO 확정 «중립»). 실제로 쓰이는 한국 이름이라 가명 티도 안 난다
- **뜻이 계정 성격과 맞는다** — 사연을 담는 사람. 이 계정이 하는 일이 정확히 그거다
- 표시 이름에 브랜드를 병기해서, 사람으로 말하되 어디 소속인지는 항상 보이게 한다

## 2. 🔴 숫자 — 쓸 수 있는 것과 절대 못 쓰는 것

CEO 지시 «숫자 넣어라»는 맞는 방향이다. 다만 **어떤 숫자냐가 법적으로 갈린다.**

### 못 쓴다 — 실측했더니 쓸 수 있는 상태가 아니다 (2026-08-21 라이브 DB)

| 항목      | 실제 값  |
| --------- | -------- |
| 회원 수   | **9명**  |
| 분석 건수 | **72건** |
| 가족 등록 | **11건** |

이용자 수·분석 건수를 프로필에 쓰려면 이 숫자를 그대로 써야 하는데 그건 홍보가 안 되고,
부풀리면 **표시광고법상 거짓·과장 광고**다(`MARKETING.md` §2 «수치 주장 — 적중률·만족도·이용자 수. 실집계 근거가 없다»).
**이용자 숫자는 실제로 쌓인 뒤에 쓴다.**

### 쓴다 — 「우리가 무엇을 얼마나 다루는가」 (전부 제품 사실, 검증 가능)

| 숫자                                      | 근거                                          |
| ----------------------------------------- | --------------------------------------------- |
| **5가지** 분야 — 사주·궁합·관상·손금·풍수 | `lib/domain/payment/feature-costs.ts`         |
| **여덟 글자** — 만세력으로 세우는 명식    | `lib/domain/saju/manse.ts` (골든 테스트 보유) |
| **10명** — 한 계정에 등록하는 가족·인연   | `membership_plans.relationship_limit`         |
| **10년 단위** — 흐름을 보는 구간(대운)    | `calculateDaeun`                              |

이 숫자들은 «많다»는 자랑이 아니라 **«한 번 보고 끝이 아니다»의 증거**라서, CEO가 원한 차별점과 정확히 같은 방향이다.

## 3. 🔴 「최초」 — 그대로 쓰면 실증 책임이 생긴다

「최초」·「유일」·「1위」는 표시광고법에서 **절대적 표현**이라, 분쟁이 나면 **우리가 입증**해야 한다.
「가족 사주 관리 서비스」의 범위를 어떻게 잡느냐에 따라 반증이 쉽게 나올 수 있고(가족 궁합·가족 운세를 다루는 곳은 이미 있다),
근거 없이 쓰면 부당한 표시로 걸린다. 그래서 **두 가지 안을 준비했고, 선택은 CEO 몫**이다.

| 안           | 문구                                       | 리스크                                                       |
| ------------ | ------------------------------------------ | ------------------------------------------------------------ |
| **A (권장)** | **「가족까지 한 계정에서 관리하는 사주」** | 사실 서술이라 리스크 0. 「최초」와 전달되는 인상은 거의 같다 |
| **B**        | 「국내 최초 가족 사주 관리 서비스」        | 실증 자료를 갖춰야 한다(경쟁사 조사 문서). 갖추면 쓸 수 있다 |

B를 택하면 발행 전에 **경쟁 서비스 조사 1장**을 만들어 두는 걸 권한다 — 그게 실증 자료가 된다.
