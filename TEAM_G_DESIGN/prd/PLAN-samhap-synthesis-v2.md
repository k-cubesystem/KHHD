# PLAN — 종합사주풀이(삼합) v2 「삼재교차법(三才交叉法)」

- 작성일: 2026-07-25
- 대상: `app/actions/ai/samhap.ts` + 파서 + 결과 UI
- 배경: 사용자 진단 — "종합 분석이 오히려 개별 사주·관상·손금·풍수보다 내용이 떨어진다.
  이게 우리 사주분석 시스템의 핵심이 될 것" → 방법론부터 재설계

## 1. 현행 진단 — 왜 5만냥짜리가 2만냥짜리보다 얕은가

코드 실측 (`app/actions/ai/samhap.ts` vs `app/actions/ai/cheonjiin.ts`):

| 축          | 천지인(개별, 2만냥)                                                                                                    | 삼합(종합, 5만냥)                                                                               |
| ----------- | ---------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 사주 데이터 | `buildMasterPromptForAction` → 풀 엔진(격국·용신 5단계·십성·십이운성·신살·지장간·합충형해파·신강약 점수제·물상론·대운) | `resolveSaju` — **일간·나이·오행분포 4필드**                                                    |
| 관상·손금   | 원본 이미지 멀티모달 재분석                                                                                            | 저장 평가문장 **90~120자 클립** (구조 필드 소실)                                                |
| 방법론 지시 | STEP 1~3 + 교차분석 규칙 + 궁위 매핑                                                                                   | "합치점을 찾아라" 1문단                                                                         |
| 토큰        | `maxTokens: 16384`                                                                                                     | **미설정** (모델 기본값)                                                                        |
| 모델 티어   | `FEATURE_MODELS.cheonjiin` = PRO                                                                                       | `getModelConfig('samhap')` 미등록 → **FLASH 폴백** 경로(직접 호출로 우회 중이나 중앙화 시 함정) |
| 인프라      | `generateAIContent` 중앙 계측                                                                                          | 직접 `genAI` 호출                                                                               |
| 출력        | 대형 JSON(과거회고 4시점·천지인 3장·용신 활용…)                                                                        | 태그 11개 → 카드 10장                                                                           |

핵심 원인: **종합 리포트가 정작 사주를 제일 얕게 보고, 관상·손금의 구조 데이터를 버리고,
교차 "방법"을 AI에게 가르치지 않는다.** 그러니 출력이 "사주도 좋고 관상도 좋으니 좋다"식
병렬 나열에 머문다.

## 2. 문헌 근거 (2026-07-25 조사)

- **삼정(三停)**: 상정(이마~눈썹)=초년 1~30세, 중정(눈썹~코끝)=중년 31~50세,
  하정(코끝~턱)=말년 51세~ — 얼굴 자체가 인생 시간표라는 상학 원리
  ([충청일보 — 삼정으로 보는 초·중·말년운](https://www.ccdailynews.com/news/articleView.html?idxno=65738)).
  우리 FACE 결과의 `ageFortuneFlow(youth/middle/senior)`가 이미 이 구조로 저장돼 있음.
- **오관(五官)·십이궁(十二宮)**: 관록궁(이마)=관운, 재백궁(코)=재물, 처첩궁(눈꼬리)=배우자,
  명궁=전체 운 등 — 부위별 운세 영역 지도
  ([운세길 관상 가이드](https://saju.nomadinfo.co.kr/guide/gwansang)).
- **오행형(五行形)**: 사람 얼굴을 木·火·土·金·水 다섯 형으로 분류, 기색과 함께 판정
  ([스카이데일리 — 오행형, 사람을 다섯가지로 분류](https://www.skyedaily.com/news/news_spot.html?ID=83216),
  [투데이신문 — 오행이 관상에서 어떻게 사용되는가](https://www.ntoday.co.kr/news/articleView.html?idxno=19714)).
  우리 FACE 결과의 `personalityType`(목형~수형)과 `[[ELEMENT_FORM]]` 태그(P2-13)가 이미 이 값.
- **체용론(體用論)**: 명리학이 체(體·본질)와 용(用·발현)의 틀을 수용해온 학술 계보
  ([KCI — 명리학 관점에서 체용론 수용양상 연구](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002968943)).
  → 사주(命)=체, 관상·손금(相紋)=용 이라는 본 설계의 학술적 골격.
- **심상(心相)**: 상은 고정이 아니라 마음가짐·삶에 따라 변한다는 관상학 내부 논리
  ([KCI — 관상의 성립과 심상(心相)에 관한 연구](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002564501)).
  → "명(불변)과 상(가변)이 어긋난 지점 = 개운의 표적"이라는 상충 해석의 근거.
- **손금 = 가변 기록**: 4대선(생명·두뇌·감정·운명)의 의미와 "손금은 고정된 운명이 아니라
  현재 상태와 잠재 흐름이며 변한다"는 통설
  ([사주살롱 — 손금 보는 법 가이드](https://sajusalon.co.kr/palmistry-guide-v2)).
- **전통 서열 격언**: 一命二運三風水 四積陰德五讀書 (명→운→풍수→행실→공부) — 층위별
  가중과 개운 행동의 자리를 주는 전통 격언(청대 소설 『아녀영웅전』 계통에서 통용).
  → 리포트 레이어 서열: 命(설계도) > 運(시간) > 宅(환경) > 行(처방)의 근거.

학술 논문 중 명리×관상 **직접 통합 방법론**은 확인되지 않음 — 즉 아래 교차법은 고전
원리들을 우리 데이터 구조에 맞춰 해화당이 독자 조립한 것이다(마케팅 문구에서 "논문으로
검증된" 류 표현 금지).

## 3. 방법론 — 삼재교차법(三才交叉法)

세 층을 **병렬 나열하지 않고 교차 검증**한다. 层: 天=命(사주 원국+대운, 불변 설계도) /
人=相·紋(관상=현재 발현, 손금=누적 궤적 — 둘 다 가변) / 地=宅(풍수, 환경 계수).

### 교차 4축 (프롬프트에 절차로 강제)

1. **오행 정합(五行整合)** — _코드가 결정론 계산_ 후 프롬프트 주입
   - 일간·용신(엔진 `finalYongsin`) vs 관상 오행형(`personalityType`) vs 풍수 지배오행
   - 상생/비화/상극 판정 → **삼재 정합도 점수**(아래 §4) + 근거 문장
2. **궁위-십성 대응(宮位十星對應)** — 매핑표를 프롬프트에 제공
   | 주제 | 사주(십성) | 관상(궁위) | 손금(선) |
   | --- | --- | --- | --- |
   | 재물 | 재성 | 재백궁(코) | 재물선·태양선 |
   | 일·명예 | 관성·인성 | 관록궁(이마) | 운명선 |
   | 인연 | 배우자성(재/관) | 처첩궁(눈꼬리)·부부좌 | 감정선·결혼선 |
   | 건강·바탕 | 일간 강약·인성 | 명궁·기색·귀 | 생명선 |
3. **시간축 삼중 정렬(時間軸三重整列)**
   - 대운 10년 단위(엔진 [현재] 태그) ↔ 삼정(초년/중년/말년 = `ageFortuneFlow`) ↔ 손금
     흐름(운명선 하부→상부) → 현재 나이가 속한 구간에서 세 시간표가 같은 말을 하는지 판정
4. **판정 언어 3단계** — 주제마다 반드시 판정
   - **합(合)**: 삼재 일치 → 확언 강도 상향("사주에서도, 코에서도, 재물선에서도")
   - **반합(半合)**: 2:1 → 다수 근거와 소수 근거를 명시하고 주도권 해석
   - **충(沖)**: 상충 → 체용론으로 해석. 명(體)은 그릇, 상·문(用)은 현재 쓰임 —
     상충은 "명대로 못 살고 있다"(회복 처방) 또는 "노력으로 명을 넘고 있다"(강화 처방)의
     신호이며 **개운 처방의 1순위 표적**. 공포 아님.

### 풍수의 자리

사람(命·相·紋) 판정이 끝난 뒤 지배오행·길방을 **용신 보완 배치**로 연결(격언의 3순위).
처방(REMEDY)은 음덕·행동(4~5순위) 층에서 "오늘부터 가능한 행동"으로.

## 4. 삼재 정합도 (결정론 스코어)

`lib/domain/analysis/samhap-coherence.ts` (순수함수, 단위테스트):

```
base 60
관상 오행형 × 용신: 동일 +16 / 상생(형→용신) +12 / 피생 +5 / 형이 용신을 극 -12 / 용신이 형을 극 -5
관상 오행형 × 일간: 동일 +8 / 상생 +5 / 피생 +3 / 극 -8 / 피극 -4
풍수 지배오행 × 용신: 동일 +10 / 상생 +7 / 피생 +3 / 극 -10 / 피극 -4
clamp [15, 98] → 등급: ≥85 합 / ≥65 반합 / <65 충
관상 오행형 미확인 시 → null (score는 기존 관상·손금 평균 폴백, 프롬프트에 미확인 고지)
```

`score` 의미 변경: 관상·손금 평균(무의미한 재탕) → **삼재 정합도**. UI 링 라벨 `정합`.

## 5. 출력 스키마 v2 (파서 하위호환)

기존 태그 전부 유지(구 리포트 재열람 호환) + 신규 태그. 신규는 콤마 충돌 없는 `|` 구분:

```
[[SUMMARY: …]]                       (유지)
[[NOW: 현재 대운·구간 이름 | 삼정·손금과 겹쳐 본 현재 국면 진단]]        (신규)
[[CROSS_WEALTH: 합|반합|충 | 사주·관상·손금 근거를 한 문단에 엮은 해석]]  (신규)
[[CROSS_CAREER / CROSS_LOVE / CROSS_HEALTH: 동일 형식]]                  (신규)
[[HARMONY_1~3]] [[TENSION]] [[TIMING_1~3]] [[REMEDY_1~3]]               (유지 — TENSION 내용은 체용 상충으로 재정의)
```
