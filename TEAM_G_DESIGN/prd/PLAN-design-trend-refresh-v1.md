# PLAN — 디자인 트렌드 리프레시 v1 (2026-08-20)

> 근거: 2026-08-20 디자인 감사(종합 A-, AI슬롭 A) + 2025-26 트렌드 리서치(출처 30여 건).
> 감사 보고서: `~/.gstack/projects/k-cubesystem-KHHD/designs/design-audit-20260820/`

## 0. 전략 한 줄

**장식을 더하지 않는다 — 이미 가진 것(전통 미학·절제·결정론 엔진)의 «질»을 올린다.**

국내 경쟁사(포스텔러·점신)는 전부 밝고 가벼운 카드 UI 문법이다. 해화당의 다크·전통·의례적 톤은
국내에서 Co-Star 포지션(조용한 프리미엄 에디토리얼)을 독점할 수 있는 빈 자리이고, 2026 글로벌
트렌드(텍스처·표현적 타이포·마이크로인터랙션·다크 심화)가 정확히 이 방향으로 불어온다.
트렌드를 좇는 게 아니라, **트렌드가 우리 쪽으로 온 것**이다.

## 1. 개선안 5건 (우선순위순)

### P1. 타이포그래피 2-스케일 시스템 — 감사 약점 1번 해소

- **무엇**: 풀이 본문용 «에디토리얼 스케일»(비율 1.333, Noto Serif KR 디스플레이를 지금보다 과감하게)과
  UI 컴포넌트용 «타이트 스케일»(1.2)을 분리해 토큰화. 현재 H3 12~13px 남발·H2 14/20/22.4px 혼재를
  토큰 강제로 소거.
- **왜 지금**: 감사에서 유일한 B 등급(Typography). 2026 트렌드 1순위(expressive typography)와
  Co-Star식 프리미엄의 핵심이 타이포 질. 4050 가독성 규율(본문 16px+·고대비)과 충돌 없음.
- **범위**: `app/globals.css` 헤딩 계층 + `tailwind.config.ts` fontSize 토큰 + 위반 스윕(프로필·허브 H3).
  `scripts/check-design-tokens.mjs`에 스케일 밖 임의 폰트 크기 게이트 추가.
- **공수**: CC 반나절~1일. **리스크**: 낮음(CSS 중심). 스윕 범위가 넓어 화면별 육안 확인 필요.

### P2. 한지·먹 텍스처의 전면 격상 — «배경 장식 → UI 재료»

- **무엇**: 이미 보유한 한지 모티프(`hanji-card`)를 ① 카드 표면 질감(종이 결+미세 그레인)
  ② **먹 번짐 리빌**(풀이 로딩→본문 등장 전환) ③ 로딩 상태(붓획 스트로크)로 확장.
- **왜 지금**: 2026 글로벌 트렌드(tactile texture·grain)와 앱 고유 자산이 정확히 겹치는 유일한
  지점. 경쟁사가 흉내낼 수 없는 차별화. «AI 슬롭의 반대편»을 더 밀어붙이는 수.
- **범위**: globals.css 텍스처 유틸리티 + 풀이 결과 화면(공용 `saju-reading-sections.tsx` — 기록·라이브
  동시 적용) + 로딩 컴포넌트. **정적 CSS 강제**(styled-jsx 함정 기지식), 텍스처는 base64/SVG 경량.
- **공수**: CC 1~2일(에셋 포함). **리스크**: 중 — 질감 과하면 가독성 하락. 렌더 스케일 육안 검증
  필수(축소본 함정 기지식), prefers-reduced-motion 준수.

### P3. 의례화된 마이크로인터랙션 — 감사 약점 2번 해소

- **무엇**: 범용 바운스가 아니라 **의례의 순간**에만 집중 투자 —
  ① 척전 엽전 던지기 물리감 ② 기도 올릴 때 촛불 글로우 펄스 ③ 풀이 CTA 탭 시 금박 반짝
  ④ 데일리 출석 도장 «쿵» 찍힘. 각 300ms 이하, transform/opacity만.
- **왜 지금**: 2026 모바일 트렌드 공통 1순위 + 기원(祈願)·출석 리텐션 시스템과 직결(의례감이
  곧 습관 장치). 4050에는 급격한 모션 금물 — 부드럽고 짧게.
- **범위**: 신당 기도 버튼·척전·출석 체크·풀이 CTA 4곳. 정적 CSS + `.next` CSS grep 게이트.
- **공수**: CC 1일. **리스크**: 낮음(포인트 투자, 전면 아님).

### P4. 신뢰 신호 + 4050 인지 부하 설계

- **무엇**: ① 풀이 하단 «이 풀이의 뿌리» 접이식 섹션(명식 근거 — 어떤 간지·오행 배치에서 이
  해석이 나왔는지) ② 사주 입력·결제 플로우 단계 표시(1/3, 2/3…) ③ 본문 저대비 잔존 구간
  스윕(ink-light/40~50 본문 텍스트 → 55 이상).
- **왜 지금**: 1차 타깃(4050 여성)의 의사결정은 신뢰 신호가 좌우(점신=후기로 해결, 해화당은
  **결정론 엔진의 근거 투명성**으로 — 이미 가진 것). JMIR 고령 UX 가이드라인과 일치.
- **범위**: 공용 풀이 렌더러 + 입력 폼 2곳 + 대비 스윕. 근거 데이터는 기존 엔진 출력 재사용(신규 계산 없음).
- **공수**: CC 1~2일. **리스크**: 낮음. 문구는 §31 고지 규율(단정 금지) 준수.

### P5. 스크롤 내러티브 풀이 + 9:16 공유 카드 출구

- **무엇**: ① 장문 풀이(최근 3배 증량)를 섹션별 절제된 페이드 리빌로 서사화(과한 스크롤 트리거
  금지 — 4050 배려) ② 풀이 말미에 **사주 카드 1장형을 9:16 세로 이미지로 저장/공유**
  (인스타 스토리·스레드 유통 단위).
- **왜 지금**: 완독률(입구)과 바이럴(출구)을 디자인 한 벌로 해결. 2030 커플 궁합(2차 타깃)의
  유입 채널 부재를 보완하고, 스레드 콘텐츠 엔진·/ilgan 퍼널과 접속.
- **범위**: 공용 렌더러 리빌 + MasterpieceSection → 캔버스/서버 OG 이미지 내보내기(기존
  `/api/og` 인프라 재사용 가능). 공유 이미지에 «AI 풀이» 고지 동판 필수(표시광고법 규율).
- **공수**: CC 2일. **리스크**: 중 — 공유 이미지 폰트 회귀 함정(OG truetype 기지식) 주의.

## 3. CEO 결정 큐

1. **P1~P5 착수 순서 승인** — 권장: P1→P3(공수 낮고 체감 큼) 먼저, P2·P4 병행, P5는 스레드 퍼널 일정과 동조.
2. **푸터 법적 링크 대비**(10px/40%) — 낮게 둔 것이 의도인지. WCAG 관점 상향 권장.
3. **색동 스트립+주홍 보더 카드** — 단청 의도 확인(주홍 보더가 «오류»로 읽힐 소지).
4. **일진 연동 홈 무드**(결정론적 개인화) — P2 이후 후속으로 갈지.
5. **큰 글씨 모드**(4050 옵션) — 시스템 폰트 배율 존중만으로 갈지, 인앱 토글을 둘지.
