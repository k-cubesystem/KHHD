# 해화당 개선 로드맵 v1 (2026-07-17)

> 세션19 시점 분석. 근거: 코드베이스 전수(신당 2.0~가족신당·통합상점), 오늘 발견·수정한 결함 패턴, 미완 기획(PLAN-shrine-guide-membership-v1, project_payment_strategy).
> 우선순위: **P0 안정성 → P1 수익 → P2 리텐션 → P3 확장**. 각 항목에 (예상 규모: 세션 단위) 표기.

---

## P0. 안정성·신뢰 (매출 이전의 전제)

1. **클라이언트 에러 모니터링 경보** (小)
   - 오늘의 로그인 크래시(React #310)는 유저 제보로 발견됨 — Sentry alert rule(클라 에러 급증 → 알림)이 없다.
   - Sentry 이슈 알림 연동 + `e2e/prod/console-probe.spec.ts`(오늘 추가)를 **배포 후 필수 게이트**로 승격.
2. **프로덕션 스모크 자동화** (小)
   - prod e2e 4종(shrine-nav·family-shrine·store·console-probe)을 배포 파이프라인/일일 cron에서 자동 실행. 현재는 수동.
3. **재화 경로 전수 감사** (中)
   - 오늘 2건 발견: 테스트충전 upsert 버그(항상 실패), 빌링 cron이 없는 RPC 호출(구독 갱신 복채 미지급).
   - `wallets` 직접 쓰기/누락 RPC를 전수 grep → 전부 `add_wallet_balance`/`deduct_wallet_balance` 원자 RPC로 통일. 구독 갱신 첫 도래 전에 완료 필수.
4. **어드민 작성 데이터 시드화 원칙 지속** (小) — 7/4 DB 재구축 소실 패턴 재발 방지. 공지(announcements)는 운영 데이터라 예외, 나머지 신규 카탈로그는 마이그레이션 시드로만.

## P1. 수익 (상점 개편의 후속)

5. **복채 실결제 퍼널 완성** (中)
   - 상점 충전 탭 → Toss 결제는 있으나 **구매 전환 계측이 빈약**. GA4 퍼널(상점 진입→탭→결제 시도→성공)과 이탈 지점 계측 추가.
   - 첫충 2배 이벤트 노출을 상점 진입 시 가이드 말풍선과 연동(오늘 만든 공지 채널 재사용).
6. **멤버십별 무료신 패키지** (中) — PLAN-shrine-guide-membership-v1 §1. 구독 가입 시 tier별 신위 증정 → 구독 전환 동기. 이미 계정공유 보유 구조라 grant만 붙이면 됨.
7. **보존기간 만료 예고 → 기억함 업셀** (小)
   - retention cron이 D-7 세션을 찾아 알림("곧 문답이 연기로 흩어집니다") → 기억함(3복채) 구매 유도. cron 1개에 SELECT 1개 추가 수준. 알림 자동화 메뉴(admin/notifications) 재사용.
8. **결제 전략 결정 실행** (待) — project_payment_strategy의 사용자 결정 4건(채널·복채팩 가격·전환장치·법무) 대기 중. 결정되면 상점 충전 탭에 반영.

## P2. 리텐션·경험

9. **신규 테마 room.webp 이미지 4종** (小) — seolbit/daljip/hongsal/byeolbat은 현재 그라디언트 폴백. 기존 이미지 파이프라인(gemini image)으로 「설빛온기」 룩 방 이미지 생성 시 구매 매력 상승.
10. **가이드 투어 고도화** (中)
    - 오늘 넣은 GlobalGuide는 localStorage 진행률 — 기기 바뀌면 초기화. 서버 저장(user_settings)으로 승격 + 신규 가입 온보딩 시퀀스(가입→사주입력→신당 강신→첫 상담)를 투어로 연결.
    - 공지 다건 롤테이션·등급 타겟팅(무료 유저에게만 업셀 공지 등).
11. **unlock_effect 2~4호** (中) — 기획서 §3 잔여: 향로(신탁 빈도 완화)·초롱(행운의 시간)·놋방울(입장 인사)·복부적(출석 +10%). 카탈로그 JSONB 선언 + 각 판정 로직에 배치 체크. 기억함으로 패턴 검증 완료라 저위험.
12. **과거 세션 검색·페이지네이션** (小) — 현재 최근 30건. 세션 축적 시 필요.
13. **가족 신당 심화** (中) — 가족 기운 프로필에 관상/손금 결과 반영(현재 사주만), 가족 신당 간 비교 뷰("우리 가족 기운 지도").
