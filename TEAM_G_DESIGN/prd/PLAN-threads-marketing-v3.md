## 0. 세계관 — 모든 글의 바탕 (CEO 08-21)

> **사주는 길을 찾는 지도다. 같은 지도를 들고도, 어떻게 읽고 쓰느냐에 따라 지름길로 가기도 하고 돌아가기도 한다.**
>
> **그리고 지도는 평생 안 변하지만 계절은 변한다. 그래서 나침반은 계속 봐야 한다 (CEO 08-21).**
> 사주는 «어떻게 살아라»가 아니라 **그때그때 상황에 맞춰 대응하기 위한 나침반**이고, 그래서 **꾸준히 챙기는 것**이다.

이 한 줄이 모든 글의 밑그림이다. 글마다 명시할 필요는 없지만, **모든 글이 이 위에서 쓰인다**:

- 우리는 길을 정해주지 않는다 — **지도를 읽어준다**. 걷는 건 본인 (효능 단정 회피와 정확히 일치)
- 나쁜 사주는 없다 — **못 읽은 지도**가 있을 뿐
- 겁을 파는 집(굿·비방 영업)과의 차별점도 이 한 줄로 선다: 낭떠러지를 그려놓고 통행료를 받는 건 지도가 아니라 장사다.
  그들은 «이거 하면 끝»이라 하고, 우리는 «이번엔 이렇게, 다음에 또 보자»고 한다
- 🔴 **«한 번 보고 끝»이 아니라는 프레임이 재방문·멤버십의 근거다** — 한 번에 끝나는 상품엔 두 번째 결제가 없다.
  이야기 끝마다 다른 문장으로 이 말을 풀어 넣는다(멘트 뱅크 TEAM_A_PM/threads-compass-lines.md, 23줄·2주 내 재사용 금지)

**지도 문장 자산** (마무리·훅에 돌려 쓴다):

1. 사주는 지도야. 같은 지도를 들고도 누구는 지름길로 가고, 누구는 3년을 돌아가.
2. 지도는 길을 안 정해줘. 근데 어느 길이 진창인지는 알려주지.
3. 모르고 헤매는 거랑 알고 돌아가는 건 완전히 달라.
4. 네 지도는 이미 그려져 있어. 안 펴봤을 뿐이지.
5. 돌아가는 길도 길이야. 알고 돌아가면 경치라도 보지.
6. 지름길은 있어. 지도를 안 편 사람한테 안 보일 뿐이야.

**프로필 소개**: «사주는 나침반. 길은 네가 걷는 거고, 나는 지금 방향을 읽어줘.» + «올라오는 사연은 본인 동의를 받은 개인 사례»
**도구 CTA 통일**: «내 지도 펴보기 → 링크» (3초 도구)

## 1. 콘텐츠 4유형 — 무엇을 왜 올리나

| 유형              | 한 줄 정의                                        | 도파민 기제                      | 노리는 반응        | 주당       |
| ----------------- | ------------------------------------------------- | -------------------------------- | ------------------ | ---------- |
| **스토리형**      | 실제 사연 → 지도가 짚은 것 → 한 일 → 좋은 결과    | 남의 인생 엿보기 + 결말의 만족   | 링크 클릭(«나는?») | 4~5        |
| **정보형**        | 포모 훅 → «이런 사람 지도엔 이게 있어» 리스트     | «나다» 자기 인식                 | 답글·친구 태그     | 3          |
| **사이다형** 🆕   | 겁 파는 업계 수법을 손님 사연으로 통쾌하게 뒤집기 | 정의 회복 카타르시스             | **리포스트**       | **2 상한** |
| **인사이더형** 🆕 | «나만 아는 것» — 업계 사람만 아는 독법·호구 방지  | 정보 비대칭 해소(비밀을 알게 됨) | **저장**           | 4          |
| **한줄형** 🆕     | 「오늘의 지도」 — 그날의 기운 두 줄(점심 전용)    | 매일 같은 시간의 시보 습관       | 팔로우·재방문      | 6          |

- 기존 기획(사연→분석→결과, E~I) = **스토리형**. 기존 A~D = **정보형**. 그 «사이»를 사이다형·인사이더형이 채운다.
- 유형마다 노리는 반응이 다르다 — 답글(정보)·리포스트(사이다)·저장(인사이더)·클릭(스토리). **네 신호를 골고루 쌓아야 알고리즘이 계정을 넓게 태운다.**

### 🔴 왜 «사이»에 이 둘이 필요한가 — 신뢰 샌드위치

스토리형은 본질이 «우리한테 온 손님 이야기»라 연속으로 쌓이면 **후기·영업으로 읽힌다**.
사이에 **«우리는 겁 안 팔아»를 증명하는 글**(사이다·인사이더 = 소비자 보호·업계 자정)이 끼어야
스토리의 링크가 영업이 아니라 초대로 읽힌다. 순환: 공감(정보) → 신뢰(인사이더) → 카타르시스(사이다) → 몰입(스토리).

**사이다형 가드레일**: 특정 업체·지역·실명 금지(«업계에 도는 수법» 일반화 프레임) · 손님 사연은 동의 · 주 2회 상한 — 매일 저격하면 «불만 계정»이 되고 카타르시스가 무뎌진다.

## 2. 새 유형 샘플

### 사이다형 J — 삼재 (미신 교정 + 통쾌)

```
"올해 삼재라 뭘 해도 안 된다"는 말에 이직을 접었다는 사람이 왔어.

사주를 펴봤어. 삼재는 맞아. 근데 삼재가 '멈추는 해'라는 건 반쪽짜리 독법이야.
이 사람 지도에서 올해는 오히려 자리를 옮겨야 트이는 해였어.
낡은 지도 한 장 때문에 좋은 길을 1년 묵힐 뻔했지.

지난주에 최종 합격했대. "삼재라며?" 하고 웃더라.

같은 지도도 읽는 사람에 따라 지름길이 되고 함정이 돼.
네 지도, 제대로 읽어줄게 → 링크
```

오백짜리 굿 얘기에 도망쳐 나온 서른다섯이 왔어.

겁을 파는 집이랑 지도를 읽는 집은 달라 → 링크

### 인사이더형 L — 점집 퇴장 신호 (저장 유도)

```
점집에서 이 말 나오면 일어나도 돼.

1. "조상이 노하셨네" — 겁부터 주는 건 읽기가 아니라 영업이야
2. "굿 안 하면 큰일 나" — 큰일이 뭔지 물어봐. 대답이 두루뭉술하면 각본이야
3. "비방 값은 현금으로만" — 더 말 안 할게

사주는 겁주는 도구가 아니라 지도야.
길이 험하면 험하다고 말해주면 되는 거지, 통행료를 받으면 안 되는 거야.

저장해놔. 부모님 모시고 갈 일 있을 때 특히.
```

### 인사이더형 M — 태어난 시간

```
태어난 시간을 몰라도 사주 볼 수 있냐고? 4분의 3은 봐.

사주는 여덟 글자인데, 시간을 모르면 두 글자가 빈 지도야.
근데 연애·직업·돈·성격은 대부분 나머지 여섯 글자에 있어.
"시간 모르면 못 본다"는 집은 두 글자 핑계로 여섯 글자 장사를 하는 거고.

엄마한테 물어봐도 "새벽이었나…" 하면 그냥 와.
여섯 글자만으로도 네 길 절반은 보여 → 링크
```

### 인사이더형 N — 우리가 제일 먼저 보는 것

```
사주 볼 때 제일 먼저 보는 건 '좋은 팔자냐'가 아니야.

뭐가 많고 뭐가 없는지를 봐. 지도로 치면 어디가 고속도로고 어디가 비포장인지.

· 좋은 사주 나쁜 사주는 없어. 잘 읽은 지도랑 못 읽은 지도가 있지

```

## 4. 확정 원고 (v3.1 유지분)

### 정보형 (A~D)

**A · 아이** — 「그 집 아이만 유독 잘 풀리는 이유」 (노력은 다들 해 → '때' 리스트 3 → 우리 아이 결정적 시기 3초)
**B · 인연** — 「내 인생에도 다시 봄바람이 불까」 (닫힌 문 세 종류 → 어디쯤 왔는지 봐줄게)
**C · 마음** — 「모두가 부러워하는 삶, 정작 너는 행복해?」 (허전함 = 내 글자가 아닌 걸로 채워서)
**D · 돈** — 「돈은 버는데 왜 안 모일까」 (돈 자리 많으면 오히려 못 모아 → 몇 개인지 3초)

### 스토리형 (E~I) — 결과·핵심 첫 줄, 사람은 한 구절, 좋은 결과까지

**E · 아이** — 「사주에 공부 글자는 있는데, 아직 때가 아니라면.」 → 학원 줄이고 고2 몰아주기 → 처음으로 시험 기간에 안 싸움 · "엄마, 나 고2 때 진짜 할게"
**F · 인연** — 「인연이 없는 게 아니라, 지난 사람이 아직 자리를 차지하고 있었어.」 → 사진부터 지우기 → 두 달 뒤 세 번째 만남 · "이번엔 안 조급해"
