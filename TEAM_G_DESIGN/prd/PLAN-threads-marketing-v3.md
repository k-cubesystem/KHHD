# PLAN — 스레드 마케팅 v3 (전면 재기획)

작성 2026-08-19 · 발주: CEO "일반 사람이 보면 무슨 말인지 모르고, 나도 해보고 싶지 않고, 재미도 없다. 다시."
v1(이벤트 시스템)·v2(복채 장부·3초 일간)를 **독자 눈**으로 다시 봤다. 결론: 시스템은 맞고 **말·주제·형식이 틀렸다.**

## 0. 왜 재미가 없었나 — 세 가지

| #   | 틀린 것                                                       | 증거                                                                                        |
| --- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 1   | **용어가 우리 것이었다.** 일간·경금·재성·장부·해화지기·야자시 | 일반인은 「일간」이 뭔지 모른다. 모르는 걸 «3초에 알려준다»고 해도 궁금하지 않다            |
| 2   | **주제가 사주였다.** 사주를 소개하려 했다                     | 사람 관심은 사주가 아니라 **자기 자신과 관계**(돈·연애·일·가족). 사주는 그걸 보는 렌즈일 뿐 |
| 3   | **형식이 «읽는 것»이었다.** 장부체 4막, 문학적 여운           | 스레드는 **반응하는 곳**이다 — «나다» «우리 엄마다» «@친구 너잖아» «🙋». 참여 장치가 없었다 |

그리고 **법무를 과하게 읽었다.** 표시광고법이 막는 건 «허위 후기·서비스 효능 단정·가짜 수치»다. 운세 장르의
«오늘 지름신 경보» 같은 문장 자체를 막는 게 아니다. 그 오독 때문에 글을 픽션 장부로 감싸 죽여 놓았다.

> **새 원칙 한 줄: 독자의 말로, 독자 얘기를, 반응하게.**

## 1. 사람들이 실제로 누르는 것 (스레드 한국 · 20~30대 · 여성 비중 높음)

스레드에서 도는 운세·성격 콘텐츠는 결국 두 엔진이다 — MBTI 가 증명한 것과 같다.

| 엔진               | 형태                                                           | 왜 도나                                      |
| ------------------ | -------------------------------------------------------------- | -------------------------------------------- |
| **나는 어떤 사람** | 「사주에 불 많은 사람 특징」 리스트 · 한 줄 칭호 · 오행 카운트 | 자기 얘기 → 캡처·공유·«나다» 답글            |
| **우리는 잘 맞나** | 「생년월일 둘 넣으면 우리 케미 한 줄」 · 「이런 커플 특징」    | 상대 태그 = 한 사람이 **두 사람**을 데려온다 |

여기에 스레드 고유 문화 셋 — **리스트형 밈**(«~인 사람 특징»), **무물**(댓글로 고민 받기), **투표**(🙋).
공통점: **첫 줄이 독자 얘기**이고 **반응할 자리**가 있다.

---

## 2. 계정의 목소리 (CEO 결정 1건)

「조선 반가의 서재」는 **제품**의 얼굴이다. 스레드 **입구**는 그 톤으로는 안 열린다.
제안: **«사주 좀 아는 친한 언니»** — 반말 아님, 구어체, 짧은 문장, 한자 금지, 전문용어는 글당 1개 이하·괄호 설명 포함, 유머 허용.
**입구는 친근, 집은 고급** — 들어오면 제품이 프리미엄이다. 이 분리를 받아들일지 CEO 가 정한다.

## 3. 글 샘플 — «이걸 누르고 싶은가»가 유일한 기준

### 3-1. 리스트형 (공감·태그) — 주 3편

```
사주에 '불'이 많은 사람 특징

· 말이 빠름. 생각보다 입이 먼저 나감
· 화 금방 냄, 금방 풂. 본인은 뒤끝 없는데 상대는 있음
· 뭐 하나 꽂히면 밤새고, 식으면 쳐다도 안 봄
· 연애는 시작이 불꽃, 유지가 숙제
· 추위 많이 탐 (진짜임)

내 사주에 불이 몇 개인지 3초 → k-haehwadang.com/saju3
※ 재미로 보는 사주 성격, 단정 아님
```

변주: 물 많은 사람 / 흙 없는 사람 / 사주에 돈 자리 많은 사람 / 배우자 자리 비어 있는 사람 / 엄마랑 사주 같은 사람

### 3-2. 무물 (댓글 접수 → 다음 날 답) — 주 2회

```
사주 보는 사람이 댓글 받습니다.

연애·돈·이직·가족·「내가 왜 이러는지」 뭐든요.
사주 안 보고도 '이럴 때 사주에서 뭘 보는지' 알려드려요.
생년월일은 남기지 마세요(공개 댓글이라). 고른 건 내일 글로.
```

다음 날:

```
어제 댓글 中 — "3년 사귄 남친이 결혼 얘기를 자꾸 피해요"

사주에서 이럴 때 보는 건 남친 사주가 아니라 본인 사주의 '배우자 자리'예요.
그 자리가 비어 있으면 늦는 거고, 다른 글자가 눌러 앉아 있으면 막히는 거라 처방이 달라요.
비어 있는 쪽은 기다리는 게 답이고, 눌린 쪽은 말을 꺼내는 게 답이에요.

어느 쪽인지 3초 → k-haehwadang.com/saju3
```

### 3-3. 투표 (참여 먼저, 내용은 내일) — 주 1~2회

```
월급 들어오면 3일 안에 반이 사라지는 사람 🙋‍♀️

댓글에 🙋 만 남겨주세요.
내일, 그런 분들 사주에 공통으로 있는 글자 하나 알려드릴게요.
```

### 3-4. 진짜 사연 (동의·익명) — 주 1~2편 · CEO 가 원한 «사연→분석→어떻게 했다»의 합법 형태

```
[실제 사연 · 본인 동의 받고 올립니다]

30대 후반 직장인 A님.
물은 것: "이직을 세 번 했는데 또 하고 싶어요. 제가 문제인가요?"
사주에서 본 것: 직업 자리가 비어 있는 게 아니라 **두 개**였어요. 한 우물이 아니라 두 우물이 맞는 구조.
A님이 정한 것: 이직 대신 지금 회사에서 직무를 하나 더 맡기로.

그 뒤는 A님 몫. 저희는 여기까지.
사연 보내고 무료로 보는 법 → 프로필 링크
```

🔴 결말은 **본인이 정한 것**으로 끝낸다(«그래서 잘 됐다» 금지 — 그게 효능 단정이다). 처음 몇 주는 사례가
없으니 **CEO 본인·지인(동의)·운영자 사주**로 시작한다 — «대표가 직접 본 내 사주»는 원래 잘 먹힌다.

### 3-5. 오늘 한 줄 (가볍게·짧게) — 평일 점심

```
8/20 수. 오늘 지름신 경보 🔴
장바구니는 채우되 결제는 내일. 내일 보면 반은 안 사고 싶어져요.
```

### 3-6. 궁합 (바이럴 엔진) — 주 1회 + 도구 안에서 상시

```
썸남·남친·남편 생년월일 아세요?

둘 다 넣으면 3초 만에 '우리 케미 한 줄' 나와요. 태그해서 같이 보세요.
결과 예: 「불과 물 — 싸우고 나면 더 붙는 커플」
→ k-haehwadang.com/saju3/match
```

## 4. 도구 — 「3초 일간」을 「3초 사주」로 (코드 90% 재사용)

오늘 만든 `/ilgan` 의 **뼈대(폼·서버 계산·공유 랜딩·OG·저장 없음)는 맞다. 주제만 틀렸다.**

| 「3초 일간」(v2)             | 「3초 사주」(v3)                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ |
| 일간 한 글자 + 상(象) 3줄    | **한 줄 칭호**(「늦게 피는 대기만성형」) + **오행 5칸 카운트**(불 3 물 0) + **돈·연애·일 세 줄**(구어) |
| 일간 공유 랜딩 10장          | 칭호별 공유 랜딩 + 오행 카운트가 카드에 찍힘 → 리스트 글(«불 3개 이상인 사람»)과 **맞물린다**          |
| —                            | **「친구랑 붙여보기」** — 생년월일 둘 → 케미 한 줄(기존 궁합 엔진 축소판) → 태그 공유                  |
| 「일간은 여덟 글자 중 하나」 | 「이건 맛보기. 여덟 글자 전부는 가입하면 복채 50만냥으로」                                             |

칭호·세 줄은 오행 분포·십성 개수에서 **결정론 규칙**으로 뽑는다(기존 `analyzeSaju` 출력 사용). 「일간」이라는
말은 화면에 **안 나온다**(각주에만). 세 줄 어미는 «~편이에요» — 단정 아님.
