## 0. 결론 — 「후기」를 쓰면 안 되고, 「장부」를 쓰면 된다

CEO 발주를 그대로 «이용자 후기»로 만들면 **두 번 막힌다**:

| 벽                                                                                                  | 결과                                                                          |
| --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 창작한 사례를 실제인 것처럼 올리면 **표시·광고법 위반**(기만적 표시광고). MARKETING.md §2 금지 항목 | 광고 심의·신고 리스크. 이미 랜딩 후기 10건도 「예시」 배지로 겨우 살아남는 중 |
| "사주 보고 취업했다" = **효험 단정**                                                                | 같은 법 위반 + 스레드 커뮤니티 신뢰 붕괴                                      |

**해법은 우회가 아니라 더 나은 형식이다.** 우리에겐 이미 웹툰 IP가 있다 —
**해화지기(집의 정령)가 조선부터 적어온 복채 장부**. 이 장부에서 한 장씩 꺼내 읽는 형식이면:

- **픽션임이 형식으로 자명** → 법적으로 안전하고, 그래서 오히려 **더 극적으로 쓸 수 있다**
- 조선·근대·현대 어느 시대든 가능 → 소재가 마르지 않는다
- 앱·웹툰·스레드가 **한 세계관**으로 묶인다 → 계정이 곧 IP
- 장부에 **번호**가 붙는다(제31장) → 수집 심리 · 아카이브 정주행
- 「찢긴 페이지(병인년)」라는 기존 떡밥 → 장기 후킹 장치가 공짜로 딸려온다

그리고 결말을 «운이 트였다»가 아니라 **«그 사람이 무엇을 바꿨나»**로 끝내면 효험 단정을 피하면서
이야기가 더 좋아진다. 사주가 미래를 맞히는 게 아니라 **사람이 자기를 알고 움직이는 이야기**가 되기 때문이다.

> 장부의 마지막 문장 규칙: **「그 뒤는 장부에 적혀 있지 않다」** — 결과를 약속하지 않으면서 여운을 남긴다.

## 4. 소재 뱅크 30

돈·일·관계 — 사람이 실제로 검색하는 것에서 출발한다. (앱 인기 주제와 정렬: 궁합·재물·직장)

**일** ⑧3년마다 이직하는 사람 ⑨상사가 유독 나만 미워한다 ⑩승진 대신 이동 발령 ⑪퇴사하고 카페를 열겠다 ⑫자격증 다섯 개인데 취업이 안 된다 ⑬동업자가 말을 바꿨다

**연애·궁합** ⑭두 번 다 같은 유형에게 끌린다 ⑮상대 부모가 궁합을 보자 한다 ⑯헤어진 사람 소식을 매일 확인한다 ⑰소개팅만 스무 번 ⑱나이 차이가 띠동갑

**가족** ⑲엄마와 사주가 똑같다 ⑳자식이 말을 안 한다 ㉑아버지 제사를 옮겨야 하나 ㉒시어머니와 한 집 ㉓형제 중 나만 다르다

**자기 자신** ㉔밤에만 살아나는 사람 ㉕결정을 못 하는 사람 ㉖이름을 바꾸고 싶다 ㉗이사 방향을 정해달라 ㉘꿈에 같은 사람이 나온다 ㉙시험을 다섯 번 떨어졌다 ㉚아무 문제 없는데 불안한 사람

시대극용 변주: 같은 소재를 조선(과거 낙방·혼사·역병)·근대(이농·전쟁)로 옮기면 30개가 90개가 된다.

## 6. 제작 파이프라인

```
소재 뱅크(30) → 대본 4막(AI 초안 + 사람 교정) → 명식 카드(OG 라우트 1080²)
                                              ↘ 웹툰 컷(kie.ai nano-banana + 캐릭터 락)
                                              ↘ 숏폼(kie.ai kling 9:16 1080×1920)
   → Supabase Storage 공개 버킷(threads-media/) → threads_posts 예약 → cron/threads-publish
```

| 단계      | 자동/수동                 | 근거                                                           |
| --------- | ------------------------- | -------------------------------------------------------------- |
| 대본 초안 | 자동(AI) + **사람 교정**  | 가드레일(효험 단정·개인 속성 단정)은 공개 지면에서 못 되돌린다 |
| 명식 카드 | 자동                      | `app/api/og/event/[token]` 전례 그대로 1080²                   |
| 웹툰 컷   | 배치 생성 → **사람 선별** | 인물 일관성은 수치로 안 잡혀 육안 필수                         |
| 숏폼      | 배치 생성 → **사람 선별** | 단가·품질 편차                                                 |
| 예약·발행 | 자동                      | 기존 크론                                                      |

**주간 운영**: 일요일 2시간에 다음 주 14편을 배치 제작·예약하고 끝낸다. 평일은 답글 승인 5분뿐.

**비용**(실측 기준): 이미지 1K 8크레딧 ≈ $0.04 → 주 12장 ≈ $0.5. 영상은 미실측 —
**첫 주 1편으로 단가부터 확정**한다.
