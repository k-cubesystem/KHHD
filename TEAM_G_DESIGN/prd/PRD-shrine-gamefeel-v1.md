# PRD-shrine-gamefeel: 신당 게임필(Game-Feel) 전면 개선 — 다각 개선안

버전: v1.0 | 작성: TEAM_G (PRD_MASTER) | 날짜: 2026-07-29
상태: DRAFT — **사용자 컨셉 선택 대기** (안별 프로토타입 → 하나씩 검수 → 확정 후 확산)

## 1. 개요

### 문제 정의 (CEO 원문 진단)

> "컨셉이나 기획은 너무 좋은데 이미지 디자인·UI가 형식적이다. **실제 게임하는 듯한
> 느낌의 액션과 효과**가 필요하다. 지금은 **배경이미지에 상만 얹혀놓은 느낌** —
> 이대로는 소비자에게 무시당한다. 가로 스크롤 넓은 방도 좋고, 가족이 함께 모이는
> 방 컨셉도 좋다. 3D나 픽셀도 좋으니 개선안을 여러 개 기획하라."

v2 「조립식 무대」로 무대 물리(원근 스케일·접지 그림자·조명 그레이딩·앵커)까지
넣었지만, 여전히 "정지된 디오라마"로 읽히는 이유를 게임 문법으로 해부하면:

| #   | 게임을 게임처럼 느끼게 하는 요소     | 현행 신당 상태                                                                  |
| --- | ------------------------------------ | ------------------------------------------------------------------------------- |
| 1   | **카메라** — 화면보다 큰 공간을 탐색 | 없음. 방 1장 = 화면 1장, 시점 고정 (`min(56vh,480px)` 단일 프레임)              |
| 2   | **시간** — 가만히 있어도 세계가 산다 | 거의 없음. 유일한 상시 모션 = 파티클·AmbientVideo. 아이템·배경·신위는 완전 정지 |
| 3   | **주민** — 살아있는 캐릭터           | 신위 = 정지 초상 1장 + 말풍선. 걷기·호흡·시선 없음. 가족은 존재 자체가 없음     |
| 4   | **주스(juice)** — 타격감·과장 반응   | 일부 있음(탭 사운드·파티클·바운스). 화면 흔들림·스쿼시·햅틱·연출 카메라 없음    |
| 5   | **의식(ritual) 연출** — 빅 모먼트    | 없음. 기도·봉헌·해금이 전부 "버튼 → 토스트 1줄"로 소비됨                        |

**결론: 에셋 품질 문제가 아니라 "정지 화면" 문제.** 5요소 중 4개가 비어 있어
어떤 그림을 얹어도 "배경 위에 스티커"로 읽힌다. 개선안은 이 5요소를 채우는
순서·방식의 조합이다.

### 목표

- 신당을 "확인하는 화면"에서 **"머무는 장소"**로 — 게임 수준의 공간감·생동감·타격감
- 체류·재방문 상승 → 기도(기원)·꾸미기 루프 강화 → 테마/신물 구매·멤버십 전환 견인

## 3. 개선안 5종 — 각각 독립 프로토타입·검수 가능

> 배타 선택이 아니다. **안1~3은 같은 무대 위에 쌓이는 레이어**(카메라·시간 → 공간 →
> 주민)이고, **안4~5는 아트 문법 선택지**다. 권장 조합은 §4.

### 안1 「살아 숨쉬는 신당」 — 주스·시간·의식 패스 (에셋 0, 코드만)

- **한 줄**: 지금 방 그대로, "정지 화면"을 죽이는 모든 것 — idle 모션·낮밤 조명·
  입장/기도 시네마틱·타격감.
- **연출 상세**
  - **상시 idle**: 촛불 스프라이트 흔들림+광원 플리커, 향 연기 상시 피어오름, 족자·
    풍경(風磬) 미세 살랑, 신위 호흡(scale 1±0.5%, 4초 주기)·눈 깜빡임 대체로 글로우 맥동
  - **낮밤 사이클**: KST 시간대별 광원 프리셋(새벽 청람 → 낮 백금 → 석양 주홍 → 밤
    촛불금). 기존 `StageLight` 그레이딩 값만 시간 보간 — 방이 하루를 산다
  - **입장 시네마틱(1.2s)**: 암전 → 문살 그림자 스치며 카메라 살짝 푸시인 → 광원
    점등 → 신위 인사. 재방문은 축약(0.5s), `prefers-reduced-motion` 시 생략
  - **기도 의식(3s)**: 기도 버튼 → 주변 UI 페이드아웃 → 카메라 제단 푸시인 → 촛불
    일제 점화 → 신위 응답 대사 → 기원 +1 카운트업 + 종소리. 매일 보는 "빅 모먼트"
  - **주스 강화**: 탭 스쿼시&스트레치(0.9→1.05→1), 빅 모먼트 미세 화면 흔들림(2px),
    `navigator.vibrate(10)` 햅틱, 사운드 레이어링(기존 useShrineAudio 재사용)
- **게임 레퍼런스**: 모뉴먼트 밸리 입장 연출, 젤다 사당 점등, 방치형 게임 idle 문법
- **재사용**: EffectsCanvas·useShrineAudio·StageLight·keeper-lines 전부 그대로 확장
- **공수**: CC 1~2세션 | **리스크**: 최소(에셋 0, 렌더 스택 유지)
- **수익 연결**: 기도 리텐션(기원 단 해금 루프) 직접 강화
- **검수 포인트**: ①입장 연출 톤 ②밤/낮 광원 색 ③기도 의식 길이(지루하지 않은가)

### 안2 「두루마리 신당」 — 가로 스크롤 확장 (CEO 아이디어 ①)

- **한 줄**: 방을 가로 2.4화면 폭 두루마리(橫卷)로 펼치고, 손가락으로 카메라를
  팬(pan)하며 **마당 — 대청 — 후원** 세 구역을 오간다.
- **공간 설계** (논리 폭 240%, 뷰포트 100%)
  - **마당(앞뜰)**: 대문·석등·삽살개·장독대. 방문객이 처음 서는 곳 — 입장 연출 시작점
  - **대청(중앙)**: 현행 신당 그대로(제단·신위·배치). **기존 배치 좌표 무손실 이관**
  - **후원(뒤뜰)**: 곳간(수납·기억함)·가족 사당 자리(안3 예약 슬롯)·성장 시각화(기원
    단이 오를수록 후원이 풍성해짐)
  - 시차(parallax) 3층: 원경(하늘·담장 0.3배) / 무대(1배) / 전경 소품(1.15배) —
    팬 할 때 깊이가 "보인다"
  - 미니맵 점 3개 + 구역 자석 스냅. 두루마리 펼침 입장 연출(가로로 스르륵)
- **게임 레퍼런스**: 싸이월드 미니홈피 확장 판타지, 어몽어스 대기실, 원신 두루마리 UI,
  스타듀밸리 농장 팬
- **재사용**: StageLayers 구조(벽지/바닥/구조물) 그대로 — 구역별 세트로 3벌 조립
- **신규 필요**: 와이드 벽지·바닥(또는 타일), 마당·후원 구조물 스프라이트 6~10점
  (기존 `scripts/shrine-assets` 파이프라인 재사용)
- **공수**: CC 2~3세션 + 에셋 1세션 | **리스크**: 가로 팬 ↔ 세로 페이지 스크롤 ↔
  편집 드래그 제스처 충돌(ARCH §4에서 해소), 배치 공간 3배에 따른 아이템 희소감 저하
  (→ 구역별 배치 상한으로 방어)
- **수익 연결**: 배치 슬롯 3배 = 신물·구조물 판매 지면 3배. 구역 자체(후원 개방)를
  기원 단·멤버십 보상으로
- **검수 포인트**: ①팬 조작감(4050 여성 타깃 — 한 손 엄지) ②구역 3개의 첫인상
  ③기존 배치가 대청에 그대로 있는가

### 안3 「가족 사랑방」 — 가족이 모이는 방 (CEO 아이디어 ②)

- **한 줄**: 가족 멤버들이 **아바타로 실제로 방에 앉아 있는** 공간. 기도한 가족은
  촛불이 켜진 방석에, 안 한 가족은 빈 방석 — 가족의 오늘이 한 화면에 보인다.
- **연출 상세**
  - 가족별 방석+등불 배치(중앙 공동 제단 둘레). **기존 가족 아바타 5종
    (`lib/domain/family/avatars.ts`) 재사용** — 앉은 자세 스프라이트 5종만 추가 생성
  - **라이브니스**: 오늘 기도한 가족 = 아바타 착석+등불 점등, 미기도 = 빈 방석+꺼진
    등불(U6 "챙기기" 트리거), 신당 열람 중인 가족 = 아바타 글로우
  - **입장 연출**: 가족이 접속하면 문 열리고 걸어 들어와 방석에 앉는다(다른 가족
    화면에 실시간 아님 — 다음 진입 시 재생, 서버 폴링 없이 저비용)
  - **상호작용**: 아바타 탭 → 그 가족 오늘의 한 줄 운세/안부 말풍선. **합동 기도**:
    당일 전원 기도 달성 시 사랑방 만개 연출 + 가족 기원 보너스(+1 추가)
  - 배치 위치: 단독 화면(신당 탭 분기) 또는 안2의 후원 구역(권장 — §4)
- **게임 레퍼런스**: 동물의 숲 광장, 스타듀밸리 축제, 카카오프렌즈 타운
- **재사용**: family_members·가족별 신당·devotion RPC(기도 여부)·아바타 5종 —
  데이터는 전부 있음, **시각화만 없던 상태**
- **공수**: CC 2세션 + 착석 스프라이트 5종 | **리스크**: 가족 없는 SINGLE 사용자에게
  빈 화면(→ SINGLE은 "가족 초대" 업셀 씬으로 전환), 가족 이름 노출 프라이버시(기존
  공개 확인 플로우 연장)
- **수익 연결**: **FAMILY 멤버십(30만/일)의 킬러 화면.** 사랑방 잠금 해제 = FAMILY
  가입 동기. 가족 방석·등불 스킨 = 신규 판매 품목
- **검수 포인트**: ①아바타 착석 모습 톤 ②빈 방석의 정서(죄책감이 아니라 애틋함으로)
  ③SINGLE 사용자 업셀 씬

### 안4 「도트 신당」 — 픽셀 아트 테마 라인 (CEO 아이디어 ③-a)

- **한 줄**: 스타듀밸리·모동숲 감성의 16-bit 도트 신당 — **전면 전환이 아니라
  유료 테마 라인**으로 판다.
- **연출 상세**: 방·제단·신물·신위 전부 도트 + **스프라이트시트 프레임 애니**(촛불
  4프레임, 향 연기 8프레임, 신위 2프레임 호흡, 삽살개 꼬리). 도트는 프레임 애니
  제작이 값싸서 "전부 움직이는 방"을 최저 비용으로 달성 — 게임 문법이 즉각 전달됨
- **브랜드 정합 (중요)**: DESIGN.md 포지셔닝은 "조선 반가 럭셔리". 도트 **전면
  전환은 브랜드 충돌** — 「설빛온기」 본선과 병행하는 **컬렉터블 테마 팩**(복고
  한정판, 기원 고단 해금 or 프리미엄 가격)으로 격리. 실패해도 본선 무손상
- **재사용**: 렌더 스택 그대로(`image-rendering: pixelated` + 스프라이트시트 CSS
  스텝 애니) — 별도 엔진 불필요
- **신규 필요**: 도트 에셋 풀셋(방 1 + 품목 12 + 신위 1 시범). 파이프라인: gemini
  생성 → 픽셀화 후처리(감색+다운스케일) 스크립트 신설
- **공수**: 파이프라인 1세션 + 에셋 1~2세션 + 렌더 0.5세션 | **리스크**: 에셋 톤
  반려 전례(앰비언트 v1~v5) — **반가 도트 1종 시범 검수 필수**
- **수익 연결**: 신규 유료 테마 라인(시즌 한정판 반복 출시 축)
- **검수 포인트**: ①도트 해상도 감(너무 거칠지/곱지 않은지) ②프리미엄 톤과의 공존

### 안5 「입체 신당」 — 3D (CEO 아이디어 ③-b)

- **한 줄**: low-poly 한옥 방을 실제 3D로 — 제한 오르빗(±15°)·실시간 촛불 광원·
  그림자. 차별화 최대, 공수·리스크도 최대.
- **기술**: react-three-fiber + drei. 번들 +150KB↑, 중저가 안드로이드 GPU 부담,
  기존 2D 배치 좌표계와 비호환(3D 재매핑 필요), 에셋 전면 재제작(모델링 파이프라인
  신설 — 이미지 생성으로 해결 불가)
- **판단**: 안1~3으로 "게임 느낌"의 8할을 훨씬 싸게 달성 가능. 3D는 그 후에도
  차별화가 더 필요할 때의 **시즌2 카드**. 이번 라운드는 **보류 권고** — 단,
  2.5D 착시(안1 카메라 푸시인+시차)로 "입체감"은 선취한다
- **공수**: CC 5세션+ | **검수 포인트**: (진행 시) 프로토 1씬 성능 실측 선행

## 4. 우선순위 & 권장 테스트 순서 (하나씩 검수)

Impact(게임필 체감+수익) × Effort:

| 안  | Impact | Effort | 판정                           |
| --- | ------ | ------ | ------------------------------ |
| 안1 | ★★★★   | ★      | **즉시 — 1차 테스트**          |
| 안2 | ★★★★   | ★★★    | **2차 — 공간 골격**            |
| 안3 | ★★★★★  | ★★★    | **3차 — 킬러 씬(FAMILY 업셀)** |
| 안4 | ★★★    | ★★★    | 병행 가능 — 테마 라인 실험     |

```
1차  안1 살아 숨쉬는 신당   ← 에셋 0·코드만. "게임 같다"의 최소 증명. 즉시 착수 가능
2차  안2 두루마리 신당      ← 카메라가 생긴 방에 공간을 붙인다 (마당·대청·후원)

```

각 차수 종료마다: **프로토타입 → 프로덕션 빌드 실기기 검수(사용자) → GO/NO-GO →

방향 확정 전에 현행 단일 화면 규격으로 에셋을 확산하면, 안2(와이드 벽지)·안4(도트)
