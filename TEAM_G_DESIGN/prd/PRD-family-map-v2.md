## 2. 빼는 것 (불필요)

- 지도의 «지도에 올릴 사람» 선택 — 가족 지도는 가족 전원, 지인은 그룹에서.
- 오행 설명 아코디언.
- 관계의 이치·실천 **문장 두 줄**(무료 노출) → AI 풀이 재료로만.
- 역할 결 문장 → 칩 둘(두꺼운·옅은)만.
- 구성원 카드의 막대·신당 링크·「가장 모자라고 넉넉합니다」 문장 → 한 줄(옅은·넉넉 칩 + 처방전).
- 가족 지도 전용 화면(FamilyEnergyMapView) — 그룹 지도 화면 하나로 통일.

## 3. 새 지도 (가족·그룹 공용) — 위에서 아래로

1. 머리: 이름 · 종류 · N명. 직장 그룹 고지.
2. **오각형 그래프** — 상생 순(木火土金水) 다섯 축, 균형(20%) 고리 금색 점선. 전체 평균은 금색 채움, 사람은 선으로 겹침. 이름을 눌러 숨김/보임. **수치 없음.**
3. **이것만 보면 됩니다** — 함께 채울 기운(든 사람 또는 물건 한 가지) · 두꺼운 기운 · 역할 결 칩 둘 · 살림 보러가기.
4. **서로의 관계** — 짝마다 한 줄: `A ↔ B · 라벨 · 오행`. 「왜·함께 무엇을」은 AI 풀이로.
5. **복채로 여는 것** — ① 그룹 전체 AI 풀이(2만냥, 있던 것) ② **둘·셋·넷 함께 보기**(3만냥, 신설): 사람을 고르면 그 조합만으로 관계를 다시 엮어 네 문단(함께 있을 때의 결 / 누가 누구에게 무엇을 / 지치는 자리와 푸는 법 / 이번 주 같이 할 한 가지). 같은 조합은 30일 캐시.
6. 구성원 한 줄씩 → 처방전.
7. BUSINESS 인쇄 문 · 오락 고지.

## 4. 처방전 ① 블록

막대 → 오각형(타고난 = 금색 채움, 살림 얹은 = 점선). 토글 없음.

> 이유로 좋다, 김지영님은 운동으로 풀고 어떤 기운을 올려 주는 게 좋다 — 해야 하는 행동·서로 피해야 하는 행동·같이 하면 좋은
> 것·같은 팀·가족이라도 조심해야 하는 것들을 오행과 사주팔자로. 팀장·사장님·엄마·아빠·모임 리더가 보는 것. 큰 기능은 아니어도 됨」

**누가 보는가** — 이미 곁에 있는 사람을 이끌고 살피는 사람: 팀을 운영하는 팀장·사장님, 가족의 기운을 관리하는 엄마·아빠,
모임의 리더. 🔴 **면접·채용 판단 용도는 넣지 않는다**(채용절차법 §9-2, 직장 그룹 고지 «채용·평가·인사 결정의 근거로 사용할 수
없습니다»). 화면 문구도 그렇게 말한다: «사람을 고르거나 재는 자리가 아닙니다».

**엔진 판정(결정론, `careOf` · `pairCautions`)** — AI 는 이것을 풀어 쓴다.

| 재료                                                 | 판정                                                                                                                                                                                                                 |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 부족한 기운(용신)                                    | 함께할 때 좋은 자리 — 木 **몸 움직이기**(걷기·첫걸음) · 火 **같이 밥**(밝은 자리·웃음) · 土 **정해진 시간**(규칙·약속) · 金 **같이 마무리**(정리·끝맺기) · 水 **쉬게 두기**(곁에 앉기·듣기) + 이유 + 해야 할 것 하나 |
| 타고난 힘(신강·신약, 엔진 정밀 점수제 5단계 → 3단계) | 신약이면 «몸 움직이기»를 가벼운 산책·쉼으로, 신강이면 «쉬게 두기»를 몸으로 풀고 쉬기로 기울인다 — 이유에 «타고난 힘이 약한/센 편» 한 줄                                                                              |
| 넉넉한 기운                                          | 피할 것 — 넘치는 쪽을 더 부추기지 않는 자리(예: 火 넉넉 → 밤늦게 들뜨는 자리 줄이기)                                                                                                                                 |
| 상극(누르는 짝)                                      | 같은 팀·가족이라도 조심할 것 — «金이 木을 치듯 A님의 딱 부러진 결정이 B님의 새 시작을 막기 쉬워요 → 처음 꺼낸 생각은 하루 두고 보기» 다섯 방향 문장. 둘 다 같은 기운이 넘치면 «같은 자리에서 부딪히기 쉬움»          |

**AI 여섯 토막** — 서로의 오행 · 장점 · 단점(조심할 것 포함) · **사람마다 이렇게**(사람마다 한 문단: 판정 그대로 + 이유 + 해야/피할 것) ·
필요한 것 · 이번 주 한 가지. 풀이 아래 「함께 있을 때 이렇게」 블록(판정 원문)과 「필요한 것」 블록이 선다. 지문에 판 번호(v6)를 넣어
옛 다섯 토막 캐시는 새로 짓는다.

**근거(조사)** — 신강은 기력이 넘쳐 과로·과식으로 기울고 신약은 쉽게 지쳐 보충이 먼저라는 통설(타이트사주 «신강과 신약» · 사자사주
«사주 건강운 가이드»), 오행별 몸의 결은 개운 표(`REMEDY_TABLE.BODY`: 木 산책·火 땀 나는 운동·土 규칙적 식사·金 호흡·水 수면)와
같은 방향으로 두었다.
