## 1. 아트 디렉션 — 「설빛 온기」 스타일 (확정)

사용자 첨부 레퍼런스(눈 내린 공원, 아이 둘) 기준. **모든 신위·테마·이펙트는 이 스타일로 통일한다.**

### 1.1 스타일 정의

| 요소 | 규정                                                                                       |
| ---- | ------------------------------------------------------------------------------------------ |
| 화풍 | 따뜻한 수채 질감의 K-애니 일러스트 (셀 애니 아님 — painterly, 부드러운 붓 터치)            |
| 눈   | 크고 또렷한 갈색 계열 눈망울 + 밝은 하이라이트 2점 (감정 전달의 중심)                      |
| 피부 | 발그레한 볼 홍조 필수 — 온기의 시그니처                                                    |
| 조명 | 따뜻한 골드 역광(backlight) + 부드러운 림라이트, 화면 전체에 온기                          |
| 질감 | 직물·퍼·머리카락의 결 묘사 (한복 원단 질감 살릴 것)                                        |
| 배경 | 보케(bokeh) 처리, 캐릭터에 포커스                                                          |
| 금지 | 차가운 색 온도 단독 사용, 공포/기괴 연출, 과도한 노출, 사실적 인체 비례(세미데포르메 유지) |

### 1.2 생성 프롬프트 템플릿 (NB2 / 외주 공용)

```
Korean traditional deity character "{이름}", warm painterly anime illustration,
soft watercolor shading, large expressive brown eyes with bright highlights,
rosy blush cheeks, warm golden backlight and soft rim light,
detailed hanbok fabric and fur textures, {외형 명세}, {감정} expression,
full body standing pose, front facing, feet visible,
solid chroma green background (#00FF00), no text, no watermark
```

- 스타일 참조 이미지: `assets-src/shrine/style-refs/` (레퍼런스 1~3장 고정 첨부 — **모든 생성에 동일 참조**)
- 캐릭터 일관성: 신위별 첫 확정본(`{code}-base.png`)을 이후 모든 표정/포즈 생성에 참조로 첨부
- 표정 차분: base와 **얼굴만 다르게** — "same character, same pose, same outfit, only change facial expression to {감정}"

### 1.3 에셋 규격 (내부 생성 · 외부 발주 동일)

## 3. 애니메이션 · 이펙트 설계

### 3.1 감정 시스템 (대화 연동)

- AI 응답 JSON에 `emotion` 필드(7종) → 클라이언트 emotionMap → 표정 차분 **크로스페이드 300ms**
- 스트리밍 시 첫 청크에 emotion 선행 배치 (표정이 말보다 먼저 바뀜)

### 3.2 상시 모션 (CSS — 에셋 추가 없음)

| 모션      | 구현                                          | 값                               |
