## 1. 개요

### 문제 정의

씬 파노라마 재제작(2026-08-07, d24aeb6)으로 배경의 **그림 품질**은 원화급이 됐다.
그러나 방은 여전히 **몇 시에 들어와도, 며칠 만에 들어와도 똑같은 그림**이다.
성공한 방/배경 게임들을 조사(§2)해 공통분모와 대조하면, 지금 신당에 없는 것은
그림이 아니라 **시간·희소성·흔적**이다:

| #   | 성공 게임의 공통분모                                                | 현행 신당                                       |
| --- | ------------------------------------------------------------------- | ----------------------------------------------- |
| 1   | 배경이 유저와 **같은 시간을 산다** (ACNH 실시간 동기)               | SceneClock 4위상 조명색 보간뿐 — 그림·하늘 불변 |
| 2   | **부재 중 사건의 증거**를 남긴다 (네코아츠메·여행개구리)            | 없음. 어제와 오늘의 방이 동일                   |
| 3   | 밤·계절 등 **통제 불가 변수에 희소 보상** (ACNH 유성우)             | 없음. 밤에 들어올 이유가 없다                   |
| 4   | 거주자가 배치물을 **실제로 쓴다** (쿠키런 킹덤)                     | 신수 2좌 배회만 — 배치물과 상호작용 없음        |
| 5   | **분위기 자체가 최대 매출원** (싸이월드 미니룸+BGM 일평균 4억 실증) | 테마 판매뿐. 계절·한정 분위기 상품 없음         |

이미 라이브인 뼈대(재사용 자산): SceneClock(KST 새벽/낮/석양/밤 조명), idle CSS 5종
(벽·걸이·숨쉬기·글로우), EffectsCanvas(향 연기·빛가루 상시, 파티클 풀 160), 신수 배회,
절차 국악 BGM + 효과음 6종, 시차 변수(`--shrine-par-*`). **뼈대는 있다 — 이 회차는
그 위에 "테마별 개성"과 "시간의 사건"을 얹는 회차다.**

### 대원칙 — 「뮤럴 불변」

검수 끝난 원화 뮤럴은 **다시 굽지 않는다**. 모든 생동은 뮤럴 위에 얹는
**레이어(틴트·광·파티클·소품 스프라이트)로만** 구현한다.
근거: ①씬 파노라마 15장 전수 육안 검수 자산 보호 ②앰비언트 영상 v1~v5 전량 반려
전례 — **영상 오버레이 금지는 유지**(AmbientVideo는 확장 동결, L1~L3 안착 후 은퇴 검토)
③레이어는 테마당 수 KB~수십 KB로 16테마 확산 비용이 통제된다.

### 목표

- 신당을 "확인하는 화면"에서 **"때마다 다른 얼굴을 보여주는 장소"**로
- 밤·절기·부재라는 시간 축의 재방문 루프 신설 → 기원(祈願)·구매 전환 견인

## 4. 기능 요구사항 — 배경 생동 5층 (L1~L5)

### L1 「하루를 사는 방」 — 시간대 연출 강화 (에셋 0, 코드+CSS만)

현행 SceneClock은 radial 조명 오버레이의 **색만** 보간한다. 이를 3요소로 확장:

1. **전면 시간대 틴트**: 위상별 사전 정의 그라디언트 레이어(새벽 청람 / 낮 투명 /
   석양 주홍 / 밤 남청) 2장을 겹치고 **opacity 크로스페이드만**으로 전환.
   신규 블렌드모드 금지 — 일반 알파 레이어(기존 soft-light 조명 1장은 그대로).
   **낮(기본)은 틴트 0** = 검수된 원화 그대로 → 원화 정본 원칙과 충돌 없음.
2. **광원 연출**: 시간대별 창빛/달빛 radial glow 스프라이트(CSS 그라디언트, 0KB)의
   opacity를 위상에 연동. 밤엔 촛불·초롱 등 **점등 아이템의 글로우가 상대적으로
   승격**(틴트 레이어 아래/위 스태킹으로 "밤에 더 빛나는" 효과 — filter 애니 금지 유지).
3. **테마별 틴트 프로파일**: 뮤럴에 시각이 이미 구워진 테마가 있다(달집·별밭=밤,
   홍살=노을). 테마당 `tintProfile`(진폭·기준 시각)로 **밤 원판 테마엔 밤 틴트를
   0으로** — 모순 방지. 16테마 값은 geometry JSON 한 곳에.

### L2 「달과 절기」 — 무속 달력 동기 (사주 앱만이 정당성을 갖는 차별화)

1. **음력 달 위상**: 기존 만세력 도메인의 음력 변환을 재사용해 실제 달 위상
   (삭~보름) 렌더. 달이 보이는 테마(프로파일로 선언)엔 벽 상단에 달 스프라이트
   1장 + 위상 마스크. **보름밤(±1일)은 은청색 특별 조명** — 보름 치성·초하루
   기도라는 무속 리듬과 앱이 같은 달력을 산다. 전례가 드문 기법(ACNH 실시간
   동기의 무속 번안)이라 차별화 포인트.
2. **5대 절기 리스킨**: 설·정월대보름·단오·추석·동지에 소품 레이어+조명 프리셋
   교체(대보름 달집·부럼 / 동지 팥죽 소반 / 단오 창포 / 추석 송편 소반 / 설 복조리).
   뮤럴 재생성 없이 **소품 스프라이트 1~3점/절기** — 쿠키런 명절 스킨·플레이투게더
   리스킨 모델. 풍경 변화는 무료(화제성), 한정 장식 판매는 §8 결정 3.

- 원칙: 큰 실루엣 소수 > 미립자 다수(모바일 정론). CSS 파티클 티어별 상한(§6).
- **잡히는 파티클(선택)**: 낮은 확률로 금빛 복(福) 조각이 떠다니고 탭하면 소액
  보상 — ACNH 벚꽃잎의 번안. 보상 경제는 §8 결정 2와 묶음.

### L4 「영험한 밤·부재의 기척」 — 재방문 루프 (서버 연동)

1. **영험한 밤**: 음력 보름(±1) 밤 + 랜덤 확률 밤(주 1~2회 수준, 서버 판정)의
   21시~04시에 하늘 기운/별똥별 연출. 탭하여 소원(1박 최대 N회, 서버 기록) →
   **다음날 아침 신당 바닥에 복 조각이 떨어져 있고 탭해 수확**. ACNH 유성우→별조각
   구조의 직역 — 이틀 연속 접속을 강제 없이 유도. 시간 판정은 **서버**(클라 시계 불신).
2. **부재의 기척**: 마지막 방문 후 24h+ 경과 시 첫 진입에 ①신수 발자국 흔적
   (다음 진입 시 소멸) ②신위의 밤 서신 1통("어젯밤 바람이 사나워 촛불을 지켰다" —
   기존 선문안 결정론 톤 재사용, **무차감**) — 서신은 서신함에 축적(동물식당 편지
   250종 모델, 기억함 연계). 죄책감이 아니라 애틋함으로(네코아츠메 무벌칙 원칙).
3. **신수×배치물 반응(P2 후행)**: 배회 신수가 향로·촛대·제물 앞에서 멈춤/응시
   모션. 특정 신수×특정 신물 전용 반응 소수(쿠키런 전용 장식 모델 — 신물 구매의
   정서 동기).

### L5 「소리의 방」 — 실음원 승격 (콘텐츠 트랙, 코드 변경 최소)

useShrineAudio는 완성돼 있고 **mp3 파일이 0개**(현재 100% 오실레이터 합성).
`fx-{key}.mp3`·`bgm-{theme}.mp3` 규약대로 파일만 넣으면 코드 0으로 승격된다.
① 효과음 6종 실음원 ② 테마 BGM 루트 16종 등록(현 4종) ③ 시간대 앰비언트 레이어
(새벽 풍경·밤 귀뚜라미·낙수 — 베이스 루프 1 + 시간대 레이어 크로스페이드, ACNH
24시간 변주의 저비용 번안). 기본 꺼짐+토글 유지. PLAN-media-tts-cost-v1과 연계.
