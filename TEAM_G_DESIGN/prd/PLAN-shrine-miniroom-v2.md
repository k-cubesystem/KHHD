## 1. 현행 진단 — "따로 논다"의 구조적 원인 5가지 (코드 실측)

현행 렌더 스택 (`ShrineRoomClient.tsx:541~660`):

```
[室] room.webp (테마별 완성 일러스트, object-cover)
 ├─ CSS 벽 블록   top 0~40%   background: var(--th-wall)   ← 일러스트 위에 덧칠
 ├─ CSS 바닥 블록 top 60~100% background: var(--th-floor)  ← 〃
 ├─ AmbientVideo (mixBlendMode:lighten, 선택적)
 ├─ CSS 제단 박스 top 47%, w 62% (gradient로 그린 DOM 사각형)
 ├─ 신위 스탠드 (일러스트 초상)
 └─ 아이템 = 이모지 텍스트 (absolute %, layer별 좌표 클램프만)
```

| #   | 원인                                                                                            | 증상                                                                                                 |
| --- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 1   | **배경이 '완성 일러스트' 한 장** — 벽·바닥·제단을 CSS 도형으로 그 위에 덧그림                   | 일러스트의 실제 원근·제단 위치와 CSS 도형이 어긋남. 테마(=그림)가 바뀔 때마다 어긋나는 정도가 달라짐 |
| 2   | **아이템이 이모지 텍스트**                                                                      | 회화적 배경 위에 플랫 이모지 → 아트 문법 자체가 이질적. "틀에 박힌 아이템"의 정체                    |
| 3   | **깊이 없음** — y좌표와 무관하게 크기 동일, z-index 정적, 그림자 없음                           | 아이템이 바닥에 "서" 있지 않고 화면에 "떠" 있음                                                      |
| 4   | **조명 미통합** — 테마 광원은 blur 타원 1개, 아이템은 조명을 받지 않음                          | 배경은 따뜻한 촛불빛인데 아이템은 원색 그대로 → 다른 공간처럼 보임                                   |
| 5   | **존(zone)이 시각 실체가 아님** — `ZONES`는 좌표 클램프 사각형뿐 (`lib/domain/shrine/zones.ts`) | hanging/wall/altar/floor 구분이 "보이지 않는 상자"라 배치 결과가 배경 구조물과 무관                  |

> 자산 현황: 배치 레이어 4종(hanging/wall/altar/floor)·드래그 저장·보유량 검증·40개 제한·
> 배치 효험 5종·기원 단 테마 해금·촛불 점화(lit)·신당지기 건네기 — **로직 골격은 이미 훌륭하다.
> 문제는 전부 '시각 계층'에 있다.** 이 골격은 유지하고 렌더·데이터 계층만 교체한다.

## 3. 새 시스템 — 「조립식 무대」 모델

### A. 배경의 해체 — 완성 일러스트를 버리고 무대를 조립한다 (원인 1·5 해결)

```
새 렌더 스택 (뒤→앞)
 L0 벽지(wallpaper)     ← 카탈로그 품목 (테마 기본값 제공, 교체 가능)
 L1 바닥재(flooring)    ← 〃
 L2 구조물(structure)   ← 제단·선반·창 — 스프라이트 아이템 (제단도 드디어 '진짜 그림')
 L3 신위 스탠드         ← 기존 유지
 L4 소품(prop)          ← 자유 배치 아이템 (기존 hanging/wall/altar/floor 레이어 계승)
 L5 조명 오버레이       ← §C. 테마 광원 컬러 그레이딩 (전 레이어 위)
 L6 전경 파티클/EffectsCanvas ← 기존 유지
```

- `room.webp`(완성 일러스트)는 **레거시 모드**로 유지 — 새 세트가 없는 테마는 기존 그대로
  렌더 (한 번에 교체하지 않고 테마 단위로 세대교체). AmbientVideo 슬롯도 그대로 둔다.
- 존이 시각 실체가 된다: 제단 스프라이트의 상판 영역 = altar 존, 벽지 영역 = wall 존.
  구조물이 움직이면 존도 함께 움직인다(구조물 메타데이터가 존 좌표를 정의).

### B. 단일 아트 문법 — 이모지 세대교체 (원인 2 해결)

- 전 카탈로그 품목에 `asset_url`(webp 스프라이트) 추가. **`emoji`는 폴백으로 존치** —
  스프라이트가 없거나 로드 실패 시 기존 렌더 그대로 (하위호환·점진 교체).
- 스타일 기준: **「설빛온기」** — 17신위 초상에서 이미 확정된 스타일(따뜻한 눈빛·부드러운 채색).
  아이템 스프라이트 규격: 투명배경 webp 512², 바닥 접지선 하단 중앙, 광원 좌상단 고정
  (광원 방향을 고정해야 어떤 조합도 그림자가 일치한다).
- 제작 파이프라인: 기존 `scripts/shrine-assets/`(테마·신위 생성 스크립트) + gemini 이미지
  생성 재사용. 시드 재실행 시 태그 소실 주의(기존 메모리 교훈) — 카탈로그 갱신은 UPDATE만.

### C. 깊이·조명 통합 — 아이템이 무대 '안'에 선다 (원인 3·4 해결)

코드만으로 즉시 효과가 나는 층. 에셋 교체 전에도 이모지 상태에서 개선 체감.

1. **원근 스케일**: floor 존에서 `scale = 0.72 + (y - y_min) / (y_max - y_min) × 0.56`
   — 뒤(위)는 작게, 앞(아래)은 크게. wall/hanging은 고정 스케일.
2. **깊이 정렬**: floor 아이템 `z-index = round(y × 10)` — 앞 아이템이 뒤 아이템을 자연 가림
   (painter's algorithm). 지금은 배치 순서 고정이라 겹치면 부자연.
3. **자동 접지 그림자**: floor/altar 아이템 하단에 타원 그림자(blur, 투명도는 y에 비례) 자동 부착
   — "떠 있음"을 즉시 해소하는 가장 값싼 장치.
4. **조명 오버레이**: 테마가 `광원색·강도·방향`을 정의 → 무대 전체에 radial-gradient 컬러
   그레이딩 + 아이템에 `filter: brightness/sepia` 미세 보정. 배경과 아이템이 **같은 빛을 받는다**.
   촛불(lit) 아이템은 주변에 국소 광원 기여 — 점화할수록 방이 밝아진다(연출 인센티브).

### D. 앵커 & 반응 — 배치가 의미를 갖는다

- **앵커**: 구조물이 스냅 지점을 노출 (제단 상판 3점·선반 2점·신위 곁 1점·향로 옆 등).
  드래그 중 앵커 반경(≈6%)에 들면 자석 스냅 + 골드 링 하이라이트. 자유 배치도 여전히 허용 —
  앵커는 보너스이지 제약이 아니다(Toca Boca의 자유 + 싸이월드의 정돈을 동시에).
- **앵커 보너스**: 기존 배치 효험 5종(기억함·향로·초롱·놋방울·복부적)과 결합 —
  "제단 위에 올린 향로"는 기운 보정 +2, 연출(연기 파티클) 강화. 효험 조건이 "배치"에서
  "**의미 있는 자리에 배치**"로 깊어진다.
- **전 아이템 탭 반응**: 보기 모드에서 아이템 탭 → 흔들림 + 품목별 효과음(놋방울 소리 등,
  기존 useShrineAudio 재사용) + 마이크로 파티클. 촛불 lit 토글은 기존 유지.
- **신위 반응**: 앵커에 새 아이템을 놓으면 신위 말풍선 1줄("향이 좋구나…" — keeper-lines 확장).
