## 0. 원안 총평 & 개선 원칙

원안(CEO 기획)은 세 기능이 각각 **감정 배출(액막이) · 즉답 재미(오방기) · 장기 서약(백일기도)** 이라는
서로 다른 리텐션 주기를 커버한다 — 일간·수시·백일. 구조적으로 훌륭하며 전부 채택한다.

개선은 네 축이다:

| 축                     | 원안의 공백                         | 개선                                                                                     |
| ---------------------- | ----------------------------------- | ---------------------------------------------------------------------------------------- |
| **기존 시스템 재사용** | 100일 게이지를 신설로 기술          | 기원(devotion)·소원·파티클·사운드·결정론 엔진 **위에 얹는다** — 신규 인프라 최소         |
| **프라이버시**         | 액운 텍스트 저장 여부 미정          | **원문 무저장이 기획의 핵심 가치** — "태우면 정말 사라진다"                              |
| **법무** (L-트랙 연장) | "치유·정화 효과", 실물 굿 효능 서술 | 효능성 문구 금지 목록 + 오락 고지 + O2O 계약 조건 분리                                   |
| **단위 경제**          | 4K 실물 굿 영상 = 완주 무료 보상    | 완주 기본 보상 = **디지털 축원 영상(자동 제작, 원가 ~$1)**, 실물 굿은 유료 상품으로 분리 |

공통 기술 규율(이번 주 사고 교훈 반영): 연출 CSS 는 **app/shrine-scene.css**(styled-jsx 금지),
재화 지급은 **server-only 모듈**(공개 액션 금지), 신규 테이블은 처음부터 RLS, 문구·판정은 결정론.

## 1. 액막이 — 부적 태우기 의식 🔥

### 채택 + 개선

| 원안                         | 개선                                                                                     | 근거                                                                                                  |
| ---------------------------- | ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 액운 텍스트 작성 → 부적 변환 | 동일 + **감정 태그 6종**(불안·미련·화·걱정·미움·액운) 선택                               | 태그는 통계·회고용, **원문은 서버에 절대 저장 안 함**                                                 |
| 촛불 드래그로 태움           | 동일 — 신당 안 촛불(이미 있는 lit 시스템)에서 **불씨를 받아온다**                        | 신당 의식으로 정체성 통일, 신당 방문 유도                                                             |
| "치유의 정화" 문구           | "마음이 한결 가벼워졌습니다" 급으로                                                      | 의료·심리 **효능 주장 금지**(표시광고법 — L-트랙과 동일 기준)                                         |
| SNS 공유                     | 태운 **후**의 정화 카드만 공유(원문 노출 없는 디자인) + 기존 공유 보상(일 1회 20복) 연결 | 감정 원문이 이미지에 남으면 프라이버시 사고                                                           |
| (미정)                       | **무료 · 일 3회**                                                                        | 부정 감정에 과금하면 브랜드 훼손. 리텐션 훅으로 쓰고 프리미엄은 부적 스킨(경면주사·금박, 복채 소액)만 |

### UX 플로우 (신당 룸 내 의식)

```
신당 하단 「액막이」 → 시트: 태그 선택 + 텍스트(≤80자, "이 글은 저장되지 않습니다" 고지)
→ 경면주사 부적 렌더(세로 부적지 + 붉은 전서체 연출, 원문은 흐릿한 주문양으로 변환 표기)
→ 촛불을 부적 하단으로 드래그 → 하단부터 타오름(연소 마스크 애니 2.4s) + 재 파티클 + crackle
→ 재가 흩어지고: "액이 사그라들었습니다" + 옥수 잔 등장 + 기원 게이지 연출
→ (선택) 정화 카드 공유
```

### 기술 골자

- **연출**: 연소 = CSS `mask-image: linear-gradient` 진행 애니(키프레임, shrine-scene.css) +
  가장자리 탄 자국(mask 2겹). 재·불티 = EffectsCanvas `smoke`+`flame` 재사용, ember 색 변형 1종 추가 없이 가능
- **사운드**: useShrineAudio `crackle` 재사용
- **데이터**: `shrine_aekmak_logs(user_id, tag, burned_at)` — **텍스트 컬럼 자체가 없다**(스키마로 강제).
  일 3회 판정 = KST 카운트. RLS 본인 SELECT/서비스 쓰기. 월간 회고("이달 7개의 액을 태웠어요") 재료
- **GA4**: `aekmak_burn`(label=tag) / 공유는 기존 `claimShareReward` 흐름
- **규모**: 부적지 에셋 1~2장(~$0.07) + CC 1세션

## 2. 오방기 점괘 — 선택장애 해소 게임 🚩

### 채택 + 개선

| 원안                                   | 개선                                                                              | 근거                                                                                   |
| -------------------------------------- | --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 신령님의 한마디를 (암시적으로) AI 생성 | **결정론 문구 풀**(색 5 × 질문유형 3 × 변형 8 = 120문) — AI 0원·즉답·재현 가능    | daily-lucky.ts 전례. 지연 없는 "탁!" 즉답이 이 기능의 쾌감. AI 는 후속 옵션            |
| 옵션 입력(짜장 vs 짬뽕)                | 옵션 2~4개를 **깃발 뒤에 무작위 배정** 후 뽑기 → 색은 확신 강도, 옵션은 배정 결과 | "빨강=짬뽕" 하드코딩 불가(옵션이 자유 입력이므로). 색=톤, 배정=답 구조가 유일하게 성립 |
| (미정) 위치                            | **신당 의식** — 신당지기(거니는 캐릭터)가 오방기 다발을 들고 오는 연출            | 게임필 트랙(WalkingKeeper)과 시너지, 신당 진입 유도                                    |
| (미정) 과금                            | **일 3회 무료** → 이후 1회 복채 1만냥                                             | 바이럴 훅은 무료, 남용은 소액 과금+rate limit 로                                       |
| 결과 공유                              | 깃발 펼침 카드(질문은 카테고리만 표기 옵션)                                       | 숏폼 감성 — 고민 원문 노출은 사용자 선택                                               |

- 원문 저장: 질문 텍스트 **미저장**(로그는 색·질문유형·시각만). 액막이와 같은 원칙.
- 법무: 하단 고지 "재미로 보는 전통 놀이 점괘입니다 — 중요한 결정의 근거로 삼지 마세요"
  (금전·구매 관련 문구는 문구 풀에서 단정 어투 금지: "아껴라" → "지갑은 잠시 쉬고 싶다 하는구나").

### 인터랙션

칠성방울 소리 → 깃발 5기 셔플(교차 애니) → 유저가 한 기를 **위로 쓸어 뽑기**(drag-up) →
깃발이 펼쳐지며 색 공개 + 신당지기(또는 좌정 主神) 말풍선으로 한마디 + 색 파티클 버스트.
5색 의미는 원안 그대로 채택(빨강 대길·하양 순리·노랑 무난·파랑 신중·초록 멈춤).

### 기술 골자

- `lib/domain/fortune/obangki.ts`: 결정론 셔플·배정(시드=userId+date+seq)·문구 풀 + 테스트
- 에셋: 오방기 5장(설빛온기 톤, 접힌/펼친 2상태 — 스프라이트 5장 + 펼침은 CSS scale·rotate로) ~$0.17
- `obangki_draws(user_id, color, qtype, drawn_at)` RLS 본인 / GA4 `obangki_draw`(label=color)
- **규모**: CC 1~1.5세션 + 에셋

## 3. 백일기도(百日祈禱) & 축원 영상 보상 🕯️

### 채택 + 구조 개선 (가장 큰 수정)

**원안의 100일 게이지는 신설이 아니라 기존 기원(devotion) 시스템의 "서약 회차" 뷰다.**

| 원안                               | 개선                                                                                                                                                                                                                               | 근거                                                                                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 100일 게이지 신설                  | **서약(誓約) 트랙**: 서약 시점의 기원 total_days 스냅샷 저장 → `(현재 total_days − 스냅샷) ≥ 100` = 완주                                                                                                                           | 일별 기록 테이블 불필요. 기원 시스템 철학("끊겨도 사라지지 않는다") 그대로 — 연속 스트릭 아님, **누적 100일**                                |
| 매일 물 올리기·촛불 등 별도 액션   | 기존 **소원 기원 = 기도**(devotion 적립과 동일 사건) 그대로. 서약 중에는 기도 시 서약 진행 연출(향불이 하루만큼 타들어감) 추가                                                                                                     | 새 데일리 액션을 늘리면 기존 루프와 경쟁 — 강화가 맞다                                                                                       |
| 완주 보상 = 실물 굿 4K 영상 (무료) | **2단 보상**: ①기본(완주 전원) = **개인화 축원 시네마틱 영상**(디지털 자동 제작 — 신당 씬·좌정 主神·이름 축원 자막·Veo/기존 영상 합성, 원가 ~$1) ②**실물 굿 영상은 유료 프리미엄 상품**(완주자에게 구매 자격 개방, 가격 별도 책정) | 실물 의식은 인건비·촬영·편집이 회당 수십만 원 — 무료 보상이면 완주자가 늘수록 적자. 자격 개방 구조면 완주 동기(원안 의도)와 단위 경제가 양립 |
| 소원지 제출                        | 완주 시 제출(이건 **저장 필요** — 제작용. 수집·이용 고지 + 제작 후 파기 옵션)                                                                                                                                                      | 액막이와 달리 명시 동의 기반 저장                                                                                                            |
| 카톡/이메일 프라이빗 링크          | 마이페이지 「비밀 보물상자」 + 알림센터. 링크는 **서명 URL(만료 있음)**                                                                                                                                                            | 기존 notifications 재사용, 외부 발송은 카카오 키(D-6) 미해결이라 후속                                                                        |

- 회차제: 완주 후 **재서약 가능**(2회차, 3회차…) — 원안의 endgame 을 반복 가능한 시즌 루프로.
- 서약 UI: DevotionStrip 아래 「백일기도 서약」 — 진행 시 신당에 **백일초(百日燭)** 구조물 자동 배치
  (남은 날수만큼 초가 짧아지는 시각화 — 게임필 자산 재사용).
- 중도 상태: 실패 개념 없음(누적이므로). 다만 서약 후 30일 무기도 시 안부 신탁(기존 oracle 재사용).

### 법무·운영 (착수 전 확인 필수 — 결정 큐)

- 실물 굿: 용역 제공 주체·장소(오프라인 신당 실재?)·1회 원가·주간 처리량 상한 — **사업 결정**.
- 표시광고: 효능("액운 퇴치 효과") 서술 금지, "전통 의식 대행·기록 영상 제공"으로 서술.
  환불·촬영물 권리·개인정보(이름이 영상에 들어감) 약관 필요 — L-3 변호사 자문 항목에 추가.
- 디지털 축원 영상: 기존 Veo 파이프라인 + 신당 렌더 캡처 합성으로 **완전 자동화 가능**(승인 시 파이프라인 1세션).

### 기술 골자

- `shrine_vows(id, user_id, started_at, devotion_snapshot, target_days=100, completed_at, wish_text, video_status, video_url)` — RLS 본인, 쓰기 service_role. 완주 판정은 기도 적립 경로(shrine-wishes)에서 훅
- 진행률 = `min(100, total_days − snapshot)` — 클라 순수 계산(devotion 값 재사용)
- GA4: `vow_start` / `vow_complete` / `vow_video_view`
- **규모**: 시스템 CC 1.5세션 + 축원 영상 파이프라인 1세션(승인 시). 실물 굿 O2O 는 별도 트랙

## 4. 우선순위 · 로드맵 (게임필 트랙과의 관계)

현재 진행 중인 안2.3(제단·회전) 출하가 선행. 이후:

| 차수 | 내용                                                 | 근거                                                              | 규모      |
| ---- | ---------------------------------------------------- | ----------------------------------------------------------------- | --------- |
| R-1  | **액막이**                                           | 구현 최저가·리텐션 즉효·기존 자산(촛불·파티클·사운드) 최대 재사용 | 1세션     |
| R-2  | **오방기**                                           | 결정론 엔진 전례 있음·바이럴 훅·신당지기 연출 시너지              | 1.5세션   |
| R-3  | **백일기도 시스템**(서약·진행·완주+디지털 축원 영상) | devotion 위 뷰라 저렴, LTV 축                                     | 1.5+1세션 |
| 보류 | 실물 굿 O2O                                          | 사업·법무 결정 선행                                               | 결정 후   |

## 5. 결정 큐 (CEO)

1. **실물 굿 O2O 운영 가능 여부** — 오프라인 의식 주체·장소·회당 원가·주간 상한. (가능하면 유료 상품 설계 착수, 불가하면 디지털 축원 영상만으로 R-3 완결)
2. **오방기 무료 정책** — 일 3회 무료+이후 1만냥(권장) vs 완전 무료
3. **액막이 프리미엄 부적 스킨** 판매 여부(기본 기능은 무료 확정 권장)

## 6. KPI

액막이: 야간(21~01시) 재방문율·주간 태우기 수 / 오방기: 공유율·신규 유입 / 백일기도: 서약 전환율·완주율·재서약율·(O2O 시)상품 전환
