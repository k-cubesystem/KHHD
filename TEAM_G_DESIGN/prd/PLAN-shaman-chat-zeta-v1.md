## 3. 개편안

### A. 선문안(先問安) — 입장하면 신위가 먼저 말한다

입장 시 **AI 호출 없이 즉시** 렌더되는 결정론 오프닝. 3단 구조로 2~3개 말풍선을 시차 출력:

1. **안부** — 기억/지난 세션 인용 ("지난번엔 이직 이야기를 하셨죠")
2. **관찰** — 사주·절기·기원 단계 근거의 오늘 상태 ("오늘은 을사년 기운이 … 한 날이라")
3. **질문** — 열린 질문 **정확히 1개**로 닫아 사용자가 답만 하면 되게

방문 유형별 분기(`lib/domain/chat/greeting.ts`, 순수함수·단위테스트):

| 유형         | 조건             | 오프닝 성격                                  |
| ------------ | ---------------- | -------------------------------------------- |
| 첫 만남      | 기억·세션 0      | 신위 자기소개 + 이름 부르기 + 가벼운 첫 질문 |
| 오늘 첫 방문 | 마지막 대화 ≥1일 | 어제 이후 안부 + 오늘 기운                   |
| 오랜만       | ≥14일            | "한동안 안 보이셨어요" + 지난 고민 후속      |
| 이어서       | 같은 날 재입장   | 짧게 이어 붙임(중복 인사 금지)               |

- **무료** — 질문 횟수·복채 미차감(사용자 발화 없이 소비되면 안 됨). 차감은 기존대로 사용자 턴에서만.
- **로딩 없음** — 결정론이라 스켈레톤 없이 즉시. 타이핑 점(`TypingDots`) 연출만 짧게.
- 변주: (방문유형 × 기억유무 × 신위 × 절기) 조합으로 문장 슬롯을 채워 반복 인상 방지.
- 오프닝은 세션 메시지로 **저장**해 재입장 시 중복 생성 금지(`messages.length === 0` 조건 유지).

> **왜 AI 생성이 아닌 결정론인가**: 입장마다 AI 1콜이면 원가·지연이 붙고, 사용자가 아무 말도
> 안 하고 나가면 순손실이다. 기억 문장을 **그대로 인용**하는 결정론 템플릿이 오히려 구체적이고
> 즉시 뜬다. 실측 후 부족하면 v2에서 AI 폴리시 1콜을 옵션으로 얹는다.

### B. UI 정리 — 크롬 최소화

**헤더 8요소 → 3요소**: `뒤로` · `신위 아바타+이름(+기원 단)` · `⋯ 더보기`

- `⋯` 바텀시트로 이동: TTS 자동읽기 / 지난 대화 열람 / 새 대화 시작 / 점사 대상 선택
- **복채·남은 질문**은 헤더에서 제거 → 입력창 바로 위 **얇은 인라인 한 줄**
  ("오늘 남은 질문 7 · 충전"). 한도 임박(≤2)일 때만 강조색.
- 웰컴 오브 + 스타터 5버튼 + "매일 10회 무료" 안내 **삭제** — 그 자리를 선문안이 대신한다.
- 입력창 위 가로 스크롤 추천 질문 → **AI 질문에 대한 빠른 답 칩 2~3개**로 축소
  (질문에 답하는 형태라 대화가 끊기지 않음).

### C. 내레이션 UI

신위의 행동·분위기 묘사를 말풍선이 아닌 **중앙 정렬 이탤릭 저채도 텍스트**로 분리.
프롬프트에서 `(괄호)` 문장을 내레이션으로 출력하게 하고 파서가 분리 렌더.
예: _향 연기가 천천히 피어오릅니다._ → 몰입감을 올리고 말풍선 밀도를 낮춘다.
