# 의식 R-4 「척전(擲錢) — 엽전 세 닢」 기획서 v1

- 일자: 2026-08-01
- 지시: **"아내가 갈림길을 정하는 도구를 요청했었지. 그럼 이건 다른 도구로 제작해줘. 사용하기 쉬울 테니 이것도 신당에 버튼을 만들어서 새로운 기능으로 업데이트해줘. 오방기와 갈림길 정하는 도구는 전혀 다른 내용이지."**
- 상태: 구현·배포 완료

---

## 0. 한 줄

갈림길을 정하는 일에는 **이미 정해진 전통 해법**이 있었다 — 조선의 수도를 그렇게 정했다.

---

## 1. 전거 — 태종실록 4년(1404) 10월 6일

새 도읍을 두고 신하들이 **송도·무악·한양**으로 갈려 결정이 나지 않자, 태종이 종친 이천우·조준
등을 이끌고 **종묘**에 들어가 향을 올리고 꿇어앉았다. 왕명을 받은 이천우가 **쟁반 위에 동전을
던졌고**, 그 결과가

| 후보 | 괘         |
| ---- | ---------- |
| 한양 | **2길1흉** |
| 송도 | 1길2흉     |
| 무악 | 1길2흉     |

였다. 그래서 **한양**으로 천도했다.

즉 **길마다 엽전 세 닢을 던져 길(吉)의 수가 많은 쪽을 고르는 것**이 갈림길의 전통 해법이다.
우리가 만들 것을 조선이 이미 만들어 두었고, 왕조가 수도를 그것으로 정했다.

## 2. 오방기와 무엇이 다른가 — 섞으면 둘 다 흐려진다

|             | 오방기(문복)                             | 척전(갈림길)                   |
| ----------- | ---------------------------------------- | ------------------------------ |
| 묻는 것     | **한 가지 일** — 무슨 일이 어찌 되겠는가 | **여러 길** — 어느 쪽으로 갈까 |
| 답하는 주체 | 신(오방신장)                             | 셈(하늘에 맡긴 수)             |
| 결과물      | 공수·처방·응기·사주                      | 정해진 길 하나                 |
| 무게        | 의식                                     | 도구                           |
| 값          | 무료 3회 후 복채 1만냥                   | **무료 10회 · 복채 없음**      |

이 분리는 코드로도 강제한다 — `chuljeon.ts` 는 **obangki 를 import 하지 않는다**(테스트가 막는다).

## 3. 셈

- 갈림길 **2~4개**(태종의 세 갈래가 근거) · 각 길에 **엽전 3닢**
- 글자면(常) = 길(吉), 등면 = 흉(凶) — 상평통보 앞뒤 그대로
- 길이 가장 많은 길이 정해진다. 표기는 실록 그대로 **"2길 1흉"**
- **동수면 동수인 길만 다시 던진다** — 전거의 "결정이 나지 않자 다시". 최대 3판
- 세 판을 던져도 나란하면 **정하지 않는다**: 「하늘도 아직 고르지 않았으니 오늘은 그대 마음에
  맡기는구나」 — 억지로 하나를 고르느니 그렇게 말하는 편이 옳다

## 4. 규율

- **결과는 서버가 회차 시드로 계산한다.** 클라이언트가 정하면 "마음에 드는 답이 나올 때까지"
  되던지는 길이 열리고, 그러면 정해 주는 도구가 아니게 된다.
- **갈림길 원문은 서버로 가지 않는다.** 액션이 받는 것은 **갈래 수**뿐이고, 스키마에 텍스트 컬럼이 없다
  (컬럼 집합을 테스트가 고정: `id·user_id·ways·picked·thrown_at`).
- RLS 는 본인 SELECT 하나뿐. 기록은 `security definer` RPC 전용이고 **어드바이저리 잠금**을 쥔다 —
  감사 A3 P0-2(오방기가 50병렬로 일 상한을 뚫었던 건)와 같은 구멍을 처음부터 닫았다.
- 연출 순서는 `--cj-delay` 가 준다(setTimeout 체인 금지). CSS 는 `app/shrine-scene.css` +
  배포 게이트 등록(클래스 70종·키프레임 65종).

## 5. 공정성 — 이 도구의 핵심 품질

정해 주는 도구가 **치우쳐 있으면** 도구가 아니다. 그래서 통계 계약을 테스트로 박았다:

- 글자면 비율 45~55% (9,000닢 표본)
- 3닢 조합 8가지가 **전부** 출현
- **자리 편향 없음** — 3갈래 6,000판에서 1·2·3번 길의 당선 비율이 각각 28~39%

## 6. 진입점

신당 하단 「오늘의 의식」 독에 **네 번째 행**으로 선다(액막이 · 오방기 · **엽전 세 닢** · 백일기도).
상태 표기는 "무료 N회"가 아니라 그냥 **"N회 남음"** — 값이 없는데 있는 척하지 않는다.
전용 페이지는 `/protected/shrine/chuljeon`.
