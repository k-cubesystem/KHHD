## 1. v1 → v2 무엇이 바뀌었나

CEO 2026-08-25 심야: «사람들의 **기운을 올려주는** 기획으로. 십이간지는 큰 뜻이 없고 이쁘지도
않다. 부족한 기운을 채우는 오행, 재물운, 가족 안정·평화·건강, 연애·사랑운. 황금빛 컬러풀도
좋고 한국 테마도 좋고 화려한 것도 좋다.»

|               | v1 (폐기)     | v2 (확정)                                           |
| ------------- | ------------- | --------------------------------------------------- |
| 축            | 정체성(내 띠) | **효능(내게 필요한 운)**                            |
| 구매 이유     | 「내 띠라서」 | 「이 기운이 **필요해서**」                          |
| 개인화 데이터 | 생년(띠)      | **용신** — 사주가 알려주는 «부족한 기운»            |
| 톤            | 여명 단일     | 여명 기본 + **카테고리별 주조색**(재물=황금 극대화) |

효능 축이 더 강한 이유: 띠는 바뀌지 않지만 **필요한 운은 상황마다 생긴다**(이직=재물·성공,
연애 시작=도화, 부모 건강=가족). 재구매·팩 확장의 여지가 구조적으로 크다. 그리고 해화당의
사주 풀이가 곧 **처방전**이 된다 — «당신의 사주에는 물이 부족합니다 → 물 기운 배경화면».

- 기본 문법은 v1 「여명」 계승: 상단 1/3 남빛(시계 자리) · 민화 평면 채색 · 금 선묘 · 글자 금지.
