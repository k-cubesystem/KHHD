# 신당 가이드·멤버십·추천·음악 기획 v1 (2026-07-14)

> 사용자 요청(2026-07-14): ①충전↔멤버십 구분·기본은 멤버십 유도 ②멤버십별 무료신 패키지 ③사주 기반 신·물건 추천 ④우하단 신 아이콘 상시+머릿말 가이드 ⑤가이드바(말풍선 애니 vs 하단 가로 공지 2줄) — 기획 ⑥음악 — 기획.
> 현황: 멤버십 SINGLE/FAMILY/BUSINESS(일일 복채 한도 10/30/100만냥) + 복채 단일통화. 신위 17(수호신6 무료·명신/장군신/천신 유료). assignGuardian이 focus_areas·용신 오행으로 主神 추천(이미 존재). 신당 방에 主神·아이템·氣運(필요 기운) 표시.

## 1. 충전 ↔ 멤버십 구분 + 멤버십 유도

**문제**: 지금은 복채 충전과 멤버십이 뒤섞여 보임. 사용자가 "무엇을 왜 사는지" 모호.

**정리 원칙 (역할 분리)**
| | 멤버십(구독) | 복채(충전) |
|---|---|---|
| 성격 | **기본 배급** — 매일 자동 지급되는 복채 한도 | **추가 충전** — 한도 초과분·특별 리딩·신위/테마 |
| 유도 | **기본은 멤버십** (예측가능·매일 리텐션) | 보조(가끔 크게 쓸 때) |
| 혜택 | 일일 복채 + **무료신 패키지**(아래 §2) + 기능 해금 | 복채 잔액만 |

**멤버십 3등급 재정의 (기본 기능 전부 사용 가능 + 사용량/해금 차등)**

- **무료 회원**: 오늘의운세·기본 사주·신당(수호신6) 사용 가능. 일일 복채 소량(출석). 상세 리딩은 복채 소모.
- **SINGLE**: 일 10만냥 + 무료신 패키지 A(수호신 전체 즉시 좌정) + 광고 제거.
- **FAMILY**: 일 30만냥 + 패키지 B(명신 1종 무료 선택) + 가족 4인 궁합.
- **BUSINESS**: 일 100만냥 + 패키지 C(장군신 1종 무료) + 사업/재물 심화 리딩 무제한.

**UI 변경(구현 시)**: 멤버십 페이지 상단을 "①멤버십 구독(기본 추천, 강조)" → "②복채 충전(추가)" 2섹션으로 명확 분리. 현재 위→아래 순서·카피 재작성. 첫 진입은 멤버십 탭 기본 선택.

## 2. 멤버십별 무료신 패키지 팩

**개념**: 등급 구독 시 특정 신위를 **무료 좌정** 가능(패키지로 묶어 "이 등급이면 이 신들"이 명확).

| 등급     | 무료 패키지                            | 신위                    |
| -------- | -------------------------------------- | ----------------------- |
| 무료     | 수호신 1종(사주 추천 主神, 자동좌정)   | assignGuardian 결과 1위 |
| SINGLE   | 수호신 **6종 전체** 즉시 좌정          | 삼신/조왕/… (오행별)    |
| FAMILY   | 수호신 6 + **명신 1종 택1**            | 업신·터주 등            |
| BUSINESS | 수호신 6 + 명신 1 + **장군신 1종 택1** | 최영·임경업 등          |

**구현 노트**: `user_shrine_deities`에 grant. 등급 변경 시 패키지 재계산(admin service_role). 천신(옥황)은 여전히 유료/시즌한정 유지(§PRD 5.5). 등급 하향 시 이미 받은 신위는 보존(호의), 신규 좌정만 제한.

## 3. 사주 기반 신·물건 추천 (핵심 몰입)

**신 추천**: assignGuardian이 이미 focus_areas·용신 오행 → 主神 추천. 이를 **신위전(神位殿)에 "당신께 필요한 신" 섹션**으로 노출.

- 사주의 **필요 기운(용신)** = 부족 오행 → 그 오행을 관장하는 신위를 상위 추천(예: 木 부족 → 청목 계열 신).
- 카피: "당신의 사주엔 木 기운이 필요합니다 — 이 신이 그 기운을 채워드립니다." (근거 오행 명시)

**물건 추천**: 신당 아이템 12종을 **사주 오행 보완**으로 추천.

- 부족 오행별 아이템 매핑(예: 火 부족 → 촛불/등불, 水 부족 → 물항아리, 木 부족 → 청죽). 개운법 조사(RESEARCH-counseling-formats §풍수·§사주 개운법 6축)와 정합.
- 방 안 "필요 기운 木" 옆에 **"추천 물건: 청죽 →"** CTA. 탭 시 보관함/상점으로.
- 데이터: `shrine_item_catalog`에 `element` 태그(각 아이템의 오행) 추가 → 사용자 용신과 매칭.

## 4. 우하단 신 가이드 HUD (상시 아이콘 + 머릿말)

**요청**: 우하단에 좌정 主神 아이콘 상시 노출 + 필요 정보/가이드 머릿말.

**설계**

- 우하단 플로팅 **主神 아바타 버튼**(48px, 오행 accent 글로우). 방·신위전·상점 등 신당 하위 화면 공통.
- 탭 시 **말풍선 가이드** 펼침: 상황별 1줄 안내 + 액션.
  - 예: "오늘 출석하면 복채 1만냥이에요 →", "필요 기운 木 — 청죽을 놓아보세요 →", "인연을 2단계 올리면 다정한 대화가 열려요."
- 애니메이션: 아이콘 은은한 숨쉬기(이미 방에 있음), 새 가이드 있으면 골드 링 펄스 + 말풍선 자동 슬라이드인(3초 후 접힘).
- 데이터: 규칙 기반 우선순위(미출석 > 신위 미좌정 > 필요기운 물건없음 > 인연레벨업 임박 > 신탁). 신탁 선톡(§5.4, 이미 구현)과 연동.

## 5. 가이드바 — 2안 비교 (사용자 선택 요청)

목적: 안내·가이드·꿀팁·할 것을 눈에 띄게. 두 방식 제안.

### A안) 말풍선 애니메이션 (신 캐릭터가 말해줌)

- §4의 우하단 主神이 말풍선으로 안내. 캐릭터가 살아있는 느낌·몰입↑.
- 장점: 세계관 일관(신이 안내), 공간 절약, 이미 있는 신탁/페르소나와 자연스러움.
- 단점: 한 번에 1개만 노출, 놓치기 쉬움(자동 접힘).

### B안) 하단 메뉴 위 가로 공지바 (2줄, 상시)

- 하단 네비 바로 위에 **가로 띠 배너 2줄** 고정. 안내/가이드/꿀팁/할 것 롤링.
  - 1줄차: 오늘 할 것(출석·미좌정 신위 등, 액션 버튼)
  - 2줄차: 꿀팁/가이드(자동 롤링, 3~5초)
- 장점: 항상 보임·정보량↑·놓치지 않음. 온보딩·리텐션에 강함(할 일 체크리스트化).
- 단점: 세로 공간 차지(방이 더 줄어듦 — 방금 스크롤 개선한 것과 상충 여지), 세계관 몰입은 A보다 약함.

**추천**: **하이브리드** — 평상시 A(말풍선, 몰입) + 할 일이 쌓였을 때만 B의 1줄 슬림 바가 하단에 잠깐 등장(예: "오늘 할 것 2개"). 방 공간을 상시 뺏지 않으면서 놓침 방지. → **사용자 결정 필요: A / B / 하이브리드.**

## 6. 음악 기획

**목표**: 신당 진입 시 잔잔한 국악풍 배경음. 몰입·체류시간↑.

**구성**

- **BGM**: 신당 방 진입 시 루프(대금/가야금/은은한 풍경 소리 기반의 앰비언트). 테마별 1곡(초가=소박한 대금, 반가=가야금, 용궁=물소리+해금, 도깨비=장구 리듬).
- **효과음(이미 일부 있음)**: 좌정=방울→바라, 봉안=풍경, 탭 반응=신위 고유음(useShrineAudio 재사용).
- **컨트롤**: 헤더 스피커 아이콘(이미 있음, muted 토글)으로 BGM on/off. **기본 off로 시작**(자동재생 정책·데이터 배려) → 첫 탭 시 페이드인, localStorage 기억.
- **제작/소싱**: (a)로열티프리 국악 앰비언트 라이선스 구매(권장, 빠름) (b)AI 생성 음원(Suno 등)로 테마별 제작 — 저작권·톤 검토 필요. 파일은 `public/audio/shrine/{theme}.mp3`(루프 최적화, ~1~2MB).
- **주의**: 모바일 자동재생 차단 → 사용자 제스처(첫 탭) 후 재생. 이미 useShrineAudio가 Web Audio 기반이라 확장 용이.

**사용자 결정 필요**: 음원 소싱 방식(라이선스 구매 vs AI 생성), 기본 on/off.

## 실행 우선순위 (결정 후 착수)

1. **[P0·버그] 신당 흰 화면** — 렌더 방식 개편 배포됨(img+GPU레이어). **실기기 재확인 필요**, 안 되면 이미지 다운스케일.
2. **[P1] 충전↔멤버십 UI 분리 + 사주 신·물건 추천 노출** — 데이터(assignGuardian·item element 태그) 대부분 존재, UI 작업 위주.
3. **[P1] 우하단 신 가이드 HUD** (A안 말풍선) — 규칙 엔진 + 플로팅 버튼.
4. **[P2] 멤버십별 무료신 패키지** — grant 로직 + 등급 변경 훅.
5. **[P2] 가이드바 최종안**(사용자 A/B/하이브리드 선택 후) + **음악**(소싱 결정 후).
