- 일자: 2026-08-01

## 1. 조사 — 굿이란 무엇이고 어떻게 짜이는가

### 1-1. 굿의 큰 갈래

| 갈래               | 목적                                  | 대상        | 우리 서비스와의 관계                  |
| ------------------ | ------------------------------------- | ----------- | ------------------------------------- |
| **재수굿**         | 집안·사업의 번창에 감사하고 복을 청함 | **산 사람** | ★ 기원굿의 원형. 굿판에서 가장 흔하다 |
| 진오기굿(진오귀굿) | 망자의 천도                           | 죽은 사람   | 해당 없음(추모 기능이 생기면 별건)    |
| 병굿               | 집안의 우환·병을 물림                 | 산 사람     | 액막이와 결이 겹침                    |
| 내림굿(신굿)       | 무당이 되는 성무 의례                 | 무당 본인   | 해당 없음                             |
| 천신맞이굿         | 봄·가을 정기 굿                       | 집안        | 계절 이벤트 후보                      |

> **우리가 만들 것은 재수굿 계열의 「기원굿」이다** — 산 사람이 백 일 동안 지킨 소원을 신께
> 아뢰고 복을 청하는 굿. 망자·치병 계열은 성격도 법도도 달라 섞으면 안 된다.

### 1-2. 굿의 뼈대 — 청신·오신·송신

모든 굿거리는 이 삼단을 반복한다. **영상의 기본 문법이 여기서 나온다.**

| 단계           | 무엇을 하는가                                  | 영상 언어                                   |
| -------------- | ---------------------------------------------- | ------------------------------------------- |
| **청신(請神)** | 춤과 방울로 신을 청한다. 강신 직전의 고조      | 어둠 → 촛불 점화 → 방울, 회전하는 옷자락    |
| **오신(娛神)** | 신이 실려 그 신격의 배역을 논다. 공수를 내린다 | 정면 응시, 무복 클로즈업, 축원 낭독         |
| **송신(送神)** | 신을 위로해 돌려보낸다                         | 기를 말아 어깨에 메고 물러남, 잦아드는 소리 |

### 1-3. 열두거리 — 서울 한양굿 기준 순서

① 부정거리 ② 가망거리 ③ 말명(조상)거리 ④ 산마누라거리 ⑤ 별상거리 ⑥ **대감거리**
⑦ 제석거리 ⑧ 호구거리 ⑨ 군웅거리 ⑩ 천왕거리 ⑪ 창부거리 ⑫ 뒷전

- **부정거리**: 굿판을 씻는다. 반드시 **맨 처음**이다.
- **대감거리**: 재물·복을 맡는 대감신. 재수굿의 알맹이.
- **창부거리**: 광대·재주의 신. 흥이 가장 오르는 대목.
- **뒷전**: 굿판에 못 든 잡신까지 먹여 보낸다. 반드시 **맨 끝**이다.

> ⚠️ **규칙**: 부정으로 열고 뒷전으로 닫는다. 이 두 개는 순서를 바꿀 수 없다.
> 지역·목적에 따라 가운데 거리는 늘고 준다(광주 계열은 안당–초가망석–제석굿–씻김–고풀이–길닦음 등).

### 1-4. 무구(巫具)와 무복

- **서울 굿의 3대 무구: 부채 · 방울 · 대신칼.** 거의 모든 거리에 나온다.
- **삼지창**: 장군거리·신장거리 전용. 굵은 나무에 쇠 삼지창.
- **오방신장기**: 신장거리. 다섯 색 기를 한데 모아 감아쥔다(우리 오방기 의식과 같은 물건).
- **무복**: 거리마다 신격에 따라 갈아입는다 — 대감은 전립·쾌자, 제석은 흰 장삼·고깔, 신장은 홍철릭.
- **제상(祭床)**: 제가집이 무당의 지시대로 차린다. 떡·과일·주(酒)·시루·통돼지 등.

### 1-5. 영상 제작에 곧바로 쓰이는 사실 정리

| 항목 | 내용                                   | 영상 반영               |
| ---- | -------------------------------------- | ----------------------- |
| 색   | 오방색(청·홍·황·백·흑/녹)              | 컷 전환의 색 리듬       |
| 소리 | 징·장구·제금, 방울, 무가(巫歌)         | 배경음 3층 구조         |
| 동작 | 회전(도무), 도약, 부채 펼침, 기 흔들기 | 컷당 1동작 원칙         |
| 공간 | 신당·마당, 굿상 뒤에 신위, 앞에 제물   | 카메라는 굿상 정면      |
| 금기 | 부정한 것은 굿판에 들이지 않는다       | 오프닝은 반드시 정화 컷 |

## 2. 설계 — 「기원굿」 서비스

### 2-1. 무엇을 파는가

**백 일 동안 지킨 소원을, 그 사람 이름을 부르는 축원과 함께 굿 영상으로 만들어 드린다.**
파는 것은 영상이 아니라 **완주의 증서**다 — 그래서 백일기도 완주자에게 먼저 준다.

### 2-2. 자격과 값 (2단 구조)

| 경로            | 자격                | 값                        | 근거                                  |
| --------------- | ------------------- | ------------------------- | ------------------------------------- |
| **완주 기원굿** | 백일기도 1회차 완주 | **무료 1회**              | 백 일의 정성이 곧 값이다              |
| **청원 기원굿** | 누구나              | 복채 (금액 CEO 결정 대기) | 굿은 본디 제가집이 값을 치르고 청한다 |

> ⚠️ 완주 무료분은 **회차마다 1개**다(1회차 완주 → 1개, 2회차 완주 → 또 1개).
> 트로피와 같은 눈금이라 이미 있는 완주 판정을 그대로 쓴다.

### 2-3. 굿거리 구성 — 영상 3분 규격

전승의 열두거리를 그대로 찍을 수는 없다. **뼈대(부정→본거리→뒷전)는 지키고 가운데만 고른다.**

| #   | 거리           | 길이 | 내용                                                      |
| --- | -------------- | ---- | --------------------------------------------------------- |
| 1   | **부정거리**   | 20s  | 촛불·정화수. 굿판을 씻는다                                |
| 2   | **청배(請陪)** | 25s  | 방울·부채로 신을 청한다                                   |
| 3   | **본거리**     | 90s  | **사용자의 주신(主神)** 거리. 축원문 낭독(이름·생년·소원) |
| 4   | **대감거리**   | 30s  | 복을 나눠 받는 대목 (재수 계열이므로 고정)                |
| 5   | **뒷전**       | 15s  | 기를 말고 물러난다. 완주패가 화면에 남는다                |

**총 3분 20초.** 3번만 사용자별로 달라지고 나머지는 공통 소재를 돌려쓴다 — 제작 단가의 핵심이다.

### 2-4. 축원문(祝願文) — 문서 스펙

전승의 고축 형식 그대로다:

```
모월 모일, {사는 곳} 사는 {생년}생 {이름}이
{주신} 앞에 백 일 정성을 다 올리고 아뢰옵니다.
비옵는 바는 {소원} 한 가지올시다.
…
```

- 재료는 **이미 앱에 다 있다**: 이름·생년(프로필), 주신(신당), 소원(백일 소원), 완주 회차·일자.
- 낭독은 TTS 또는 성우. **AI 생성 문구가 아니라 결정론 조립**이라 값이 0이고 검수가 가능하다.

### 2-5. 영상 파이프라인 (힉스필드 연동 — **이번 구현 범위 밖**)

```
신청 접수 → 축원문 조립 → 컷 분할(5거리) → 소재 생성/조회 → 합성 → 자막(ASS) → 검수 → 배포
   [구현됨]      [설계됨]        [설계됨]       [힉스필드]     [ffmpeg]   [post.mjs]  [사람]  [스토리지]
```

⚠️ 이미 확보된 자산(메모리 [[project-marketing-video-pipeline]], [[project-higgsfield-setup]]):

- `post.mjs` 후처리 CLI 8종(concat·caption·audio·probe…) — 합성·자막은 그대로 쓴다
- **drawtext 금지 → ASS + libass**, ffprobe 없음, **Veo 최대 8초라 컷 분할 필수**
- 🔴 힉스필드 무료 10크레딧으로는 Veo 3.1(22크레딧) 1회도 못 돌린다 — **유료 전환이 선결**
- 미디어 산출물은 **반드시 D: 드라이브**(C: 잔여 27G)

### 2-6. 상태 기계

`requested → script_ready → queued → rendering → review → delivered`
(실패는 `failed`, 사용자 취소는 `canceled`)

**이번 구현은 `requested` 까지**다. 그 뒤 단계는 힉스필드 테스트가 끝난 뒤 붙인다.

## 3. 이번에 구현하는 것 (영상 제작 직전까지)

1. **자격 판정** — 백일 완주 회차 대비 사용한 무료 기원굿 수
2. **신청 접수** — 주신·소원·축원 대상 확인 후 접수(스키마 + RPC + 액션)
3. **진행 표시** — 백일기도 페이지에 「기원굿」 칸. 완주 전에는 **동기부여**로, 완주 후에는 신청 버튼으로
4. **축원문 미리보기** — 사용자가 무엇이 담기는지 먼저 본다(결정론 조립이라 즉시 생성)

구현하지 않는 것: 컷 생성·합성·배포·결제(청원 기원굿의 값이 미정이라 무료 경로만 연다).

## 4. 결정 대기 (CEO)

1. **청원 기원굿 가격** — 굿은 본디 값이 큰 의례다. 복채 단위로 얼마?
2. **낭독 목소리** — TTS(즉시·저렴) vs 성우(품질·단가). 초기엔 TTS 권장.
3. **본거리 소재** — 17신위 각각의 굿 장면을 만들 것인가(신위당 1컷 × 17), 아니면 공통 1컷에 신위 이미지만 합성할 것인가. 후자가 현실적.
4. **배포 형태** — 앱 안 재생만 / 다운로드 허용 / 공유 링크. 얼굴·이름이 들어가므로 공유는 신중해야 한다.
