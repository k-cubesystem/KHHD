**1. 배포 직전에 «현재 라이브»를 다시 잰다.**

**2. HEAD 가 아닌 커밋을 배포하지 않는다.**
옛 트리를 올리는 것은 그 사이 나간 것을 되돌리는 일이다. 범위를 좁히고 싶으면 배포 대신
브랜치를 정리하라.

**3. 배포 전후로 HANDOFF 에 한 줄 남긴다 — 통지 수단은 이 파일이다.**
세션 간 메시지 채널은 **모든 세션이 붙어 있지 않다.** 실제로 그날 통지 없이 배포하던 세션이
있었는데, 규칙을 어긴 게 아니라 채널을 몰랐던 것이다. 그 세션도 자기 배포를 이 파일에는
적고 있었다. 그러니 **배포 전에 「지금 `<커밋>` 배포」를 여기 커밋하고, 끝나면 배포 ID 를
덧붙인다.** 메시지도 보낼 수 있으면 함께 보내되, 이 파일이 정본이다.

**4. 더러운 워크트리에서 배포하지 않는다.**
`vercel deploy --prod` 는 git 커밋이 아니라 **작업 디렉터리를 업로드**한다. 미커밋 변경이
그대로 프로덕션에 실린다. 그날 공유 워크트리에는 다른 세션의 미커밋
`lib/supabase/middleware.ts` 30줄과 진행 중이던 journey-reward 9파일이 있었다 — 그대로
배포했으면 미완성 기능이 나갈 뻔했다.
→ `git worktree add --detach <경로> <커밋>` 으로 깨끗한 임시 워크트리를 만들고 `.vercel` 을
복사해 거기서 배포한다. 끝나면 `git worktree remove`.
⚠️ **역방향 주의**: 깨끗한 배포는 «미커밋인 채 프로덕션에만 살던 코드»를 조용히 되돌린다.
배포 전 워크트리 `git status` 를 보고, 미커밋 변경이 있으면 커밋할지 먼저 정할 것.

**5. `vercel alias set` 은 평시 금지 · 긴급 되돌리기에만.**

`feedback_deploy_branch`). **예외는 «라이브가 지금 잘못돼 있고 과거의 정상 배포로 즉시
돌아가야 할 때»** 뿐이다. 빌드를 기다리지 않고 초 단위로 되돌아간다.
→ 쓴 뒤에는 **반드시 정상 배포로 정렬**한다. 별칭이 가리키는 것과 브랜치가 어긋난 채 두면

## 5. 손대기 전에 알아야 할 함정

- **웹툰 등급을 바꾸면 본문 버킷이 바뀐다** — free=`webtoon`(공개) / membership=`webtoon-locked`(비공개).
  자동 이동은 **안 한다**. 화면이 경고만 띄우니 본문을 다시 올려야 한다.
- **멤버십 회차는 이미지 최적화를 안 탄다**(서명 주소라 캐시가 안 맞는다). 올릴 때 줄이는 것이
  유일한 방어선이다 — 운영 화면 밖으로 컷을 넣으면 원본이 그대로 독자에게 간다.
- **웹툰 컷에 `fitWithin` 을 쓰면 안 된다.** 긴 변 기준이라 2000×10000 컷의 가로가 216px 로
  뭉개진다. `fitWidth`(가로 기준)를 쓴다. 두 함수가 같은 파일에 나란히 있다.
- **사연 표만 service_role 이다.** 원문과 연락처가 함께 있는 유일한 표라 어드민 RLS 정책을
  **일부러 안 만들었다**. "어드민인데 왜 RLS 로 안 되지"라며 정책을 추가하는 건 되돌리는 결정이다.
- **React `<ViewTransition>` 은 못 쓴다.** react@19.2.4 정식 빌드에 `unstable_ViewTransition` 이
  없다(experimental 전용). 다시 조사하지 말 것.
- **styled-jsx 금지.** App Router 에서 빌드 CSS 에 한 줄도 안 실려 연출이 무증상으로 죽는다.
  연출 CSS 는 `app/shrine-scene.css` · `app/globals.css` 정적 파일에만 둔다.
- **Bash 의 cwd 는 명령 사이에 리셋된다.** git·vercel 은 반드시 `cd <경로> && 명령` 한 줄로.
  이걸 어겨서 main 에서 prod 배포가 나간 사고가 있었다.
- 🔴 **`result_json` 의 값을 곧바로 JSX 에 넣지 말 것.** `Record<string, any>` 라 타입이 못 막고,
  AI 출력 스키마는 뷰보다 먼저 진화한다. 문자열인 줄 알았던 `career` 에 객체가 와서 화면이
  통째로 죽었다(React #31). 반드시 `lib/domain/analysis/rich-field.ts` 를 거친다.
  **모양을 추측하지 말고 재라** — `select jsonb_typeof(...)` 로 라이브 DB 를 훑으면 5분이면 끝난다.
- 🔴 **`'use server'` 파일에 BOM 이 붙으면 조용히 죽는다.** 빌드·타입은 통과하고 브라우저에서만
  터진다. `no-bom.test.ts` 가 막고 있지만 새 파일 생성 경로(특히 Python heredoc)를 조심할 것.
- ⚠️ **주석 안에 `*/` 를 만드는 문자열을 쓰지 말 것** (예: glob 패턴을 백틱으로 감싼 경우).
  블록 주석이 거기서 끝나 파일 뒷부분이 통째로 깨진다 — 이번 회차에 한 번 밟았다.

- 🔴 **클라이언트 컴포넌트에서 서버 의존 모듈의 «값»을 import 하면 `next build` 가 죽는다.**
