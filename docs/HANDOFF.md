- 🔴 **프로덕션 배포(`vercel deploy --prod`)**
  `.vercel/`이 gitignore 라 프로젝트 연결 정보가 리포에 없고, Vercel CLI 로그인도 그 컴퓨터에만 있다.

  → 데스크톱 복귀 시: 워크트리에서 브랜치 확인 후 `vercel deploy --prod --yes` 한 줄로.

  `E2E_USER_EMAIL`/`PASSWORD` 가 셸에 없고 `.env*` 읽기는 금지다. 어느 기기에서도 못 한다.
  → 사람이 폰으로 직접 보는 수밖에 없다. 그래서 `?anim=1` 계측을 만들었다.

- ⚠️ **`~/.gstack/`, `~/.claude/hhd-session-checkpoint.md`**
  전부 기기 로컬이다. 다른 기기에서는 없다 — 이 파일이 그 대체물이다.

## 5. 손대기 전에 알아야 할 함정

- **웹툰 등급을 바꾸면 본문 버킷이 바뀐다** — free=`webtoon`(공개) / membership=`webtoon-locked`(비공개).
  자동 이동은 **안 한다**. 화면이 경고만 띄우니 본문을 다시 올려야 한다.
- **멤버십 회차는 이미지 최적화를 안 탄다**(서명 주소라 캐시가 안 맞는다). 올릴 때 줄이는 것이
  유일한 방어선이다 — 운영 화면 밖으로 컷을 넣으면 원본이 그대로 독자에게 간다.
- **웹툰 컷에 `fitWithin` 을 쓰면 안 된다.** 긴 변 기준이라 2000×10000 컷의 가로가 216px 로
  뭉개진다. `fitWidth`(가로 기준)를 쓴다. 두 함수가 같은 파일에 나란히 있다.
- **사연 표만 service_role 이다.** 원문과 연락처가 함께 있는 유일한 표라 어드민 RLS 정책을
  **일부러 안 만들었다**. "어드민인데 왜 RLS 로 안 되지"라며 정책을 추가하는 건 되돌리는 결정이다.
- **React `<ViewTransition>` 은 못 쓴다.** react@19.2.4 정식 빌드에 `unstable_ViewTransition` 이
  없다(experimental 전용). 다시 조사하지 말 것.
- **styled-jsx 금지.** App Router 에서 빌드 CSS 에 한 줄도 안 실려 연출이 무증상으로 죽는다.
  연출 CSS 는 `app/shrine-scene.css` · `app/globals.css` 정적 파일에만 둔다.
- **Bash 의 cwd 는 명령 사이에 리셋된다.** git·vercel 은 반드시 `cd <경로> && 명령` 한 줄로.
  이걸 어겨서 main 에서 prod 배포가 나간 사고가 있었다.
