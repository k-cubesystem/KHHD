## 이미지 넣는 법

캡처를 `images/` 폴더에 **문서에 적힌 파일명 그대로** 저장한다.
파일명은 각 문서 맨 아래 「담당자 확인표」에 있다.

②③④는 결제 유형과 무관하므로 **두 문서가 같은 파일을 함께 쓴다** —
`02-하단정보.png` · `03-환불규정.png` · `04-로그인.png` · `05-회원가입.png`

⑥번대(카드 결제경로)만 문서마다 다른 파일을 쓴다.

## 🔴 제출 전 확인 — 캡처가 샌드박스다

결제창 캡처의 주소가 `payment-gateway-**sandbox**.tosspayments.com` 이고
화면에 **「실제 결제가 안되는 테스트입니다」** 배지가 보인다.

토스가 「테스트 키로 연동해 심사 넣으라」고 안내한 것은 맞지만, **카드사 심사자가 이 배지를
보고 반려할 수 있다.** 제출 전에 토스 담당자에게 한 줄 확인할 것 —
「테스트 키 상태의 결제창 캡처로 제출해도 되는지」.

## 제출 전 체크

- [ ] 모든 캡처에 브라우저 **주소창**이 보이는가 (카드사 팝업 창은 주소가 없어도 무방)
- [ ] ②③④는 로그아웃 상태에서 찍었는가
- [ ] ⑤ 화면에 **상품명과 금액**이 함께 보이는가
- [ ] 일반결제 ⑥에 **비씨카드 페이북 결제 화면**이 포함되었는가 (누락 시 심사 불가)
- [ ] 정기결제 ⑥에 **카드 정보 입력**과 **본인 정보 입력** 두 화면이 다 있는가
- [ ] 표지의 사업자 정보가 **토스페이먼츠에 등록된 사업자등록증과 일치**하는가
