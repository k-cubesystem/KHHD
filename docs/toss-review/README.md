## 이미지 넣는 법

캡처를 `images/` 폴더에 **문서에 적힌 파일명 그대로** 저장하면 된다.
파일명은 각 문서 맨 아래 「담당자 확인표」에 있다.

두 문서가 **같은 파일을 함께 쓰는 것**이 있다 (②③④는 결제 유형과 무관하므로 한 장이면 된다) —
