## 🔴 제출 전 확인 — 캡처가 샌드박스다

결제창 캡처의 주소가 `payment-gateway-**sandbox**.tosspayments.com` 이고
화면에 **「실제 결제가 안되는 테스트입니다」** 배지가 보인다.

토스가 「테스트 키로 연동해 심사 넣으라」고 안내한 것은 맞지만, **카드사 심사자가 이 배지를
보고 반려할 수 있다.** 제출 전에 토스 담당자에게 한 줄 확인할 것 —
「테스트 키 상태의 결제창 캡처로 제출해도 되는지」.

## 제출 전 체크

- [ ] 모든 캡처에 브라우저 **주소창**이 보이는가 (카드사 팝업 창은 주소가 없어도 무방)
- [ ] ②③④는 로그아웃 상태에서 찍었는가
- [ ] ⑤ 화면에 **상품명과 금액**이 함께 보이는가
- [ ] 일반결제 ⑥에 **비씨카드 페이북 결제 화면**이 포함되었는가 (누락 시 심사 불가)
- [ ] 정기결제 ⑥에 **카드 정보 입력**과 **본인 정보 입력** 두 화면이 다 있는가
- [ ] 표지의 사업자 정보가 **토스페이먼츠에 등록된 사업자등록증과 일치**하는가

## 🔴 심사 끝나면 되돌릴 것 — 테스트 구독

「결제 수단 변경 / 해지 / 다음 결제일」이 보이는 화면을 캡처하려고, 심사용 계정
`qa@k-haehwadang.com` 에 **테스트 구독**을 넣어 뒀다(2026-08-20, CEO 승인).

- 구독 id `70f57f4a-b0b7-43b7-8d4b-6ef0db372ff6` · 싱글 멤버십 · 기간 2026-08-20 ~ 09-19
- **실결제가 아니다** — `billing_key` 가 NULL 이라 청구 크론이 집어도
  «missing billing_key» 로 건너뛴다. 돈이 빠져나갈 경로가 없다.

심사 통과 후 지운다.

```sql
update subscriptions set status = 'CANCELLED', cancelled_at = now(),
       cancel_reason = '심사용 테스트 구독 정리'
 where id = '70f57f4a-b0b7-43b7-8d4b-6ef0db372ff6';
```

심사 결과가 나오면 이 목록부터 본다.

## A. 통과하면 — 순서대로

1. **라이브 키 교체** — 토스 개발자센터에서 상점 둘의 키 4개를 받아 Vercel `hhd`(Production)에 넣는다.
   이름은 정해져 있다 — `NEXT_PUBLIC_TOSS_CLIENT_KEY` · `TOSS_SECRET_KEY` ·
   `NEXT_PUBLIC_TOSS_BILLING_CLIENT_KEY` · `TOSS_BILLING_SECRET_KEY`.
   🔴 클라이언트 키는 **빌드에 인라인**된다 — 넣고 나서 **반드시 재배포**.
2. **옛 환경변수 삭제** — `TOSS_PAYMENTS_SECRET_KEY` · `NEXT_PUBLIC_TOSS_PAYMENTS_CLIENT_KEY` ·
   고아 `TOSS_WEBHOOK_SECRET`. 코드 폴백(`lib/config/toss-keys.ts`)도 그때 걷는다.
3. **테스트 구독 정리** — 위 「심사 끝나면 되돌릴 것」 SQL 실행.
4. **테스트계정 정리** — `qa@k-haehwadang.com` 외 테스트 계정 3개.
5. **실결제 1건 검증** — 소액으로 충전 1건 · 멤버십 1건을 실제로 결제하고 취소까지 돌려본다.
   웹훅(`PAYMENT_STATUS_CHANGED`)이 들어와 복채가 회수되는지 확인.

## C. 심사와 무관하게 남은 것

1. 🔴 **등급별 한도가 전부 같다** — 싱글·패밀리·비즈니스 모두 `relationship_limit=10`,
   `storage_limit=20`. 99,000원과 12,800원의 차이가 **복채 지급량뿐**이다. 「패밀리」·「비즈니스」
   라는 이름과 설명이 더 큰 한도를 약속하는 것처럼 읽혀 표시광고법 쪽이 걸린다.
   → `membership_plans` 값만 바꾸면 화면·차감이 따라간다. **CEO 가 숫자를 정할 일.**
2. **공개 랜딩에 푸터가 안 보인다** — `k-haehwadang.com` 첫 화면이 전체화면 캐러셀이라
   스크롤이 없고 푸터 높이가 0이다. 전자상거래법 제10조는 사업자 정보를 **초기화면**에
   표시하도록 한다. 지금은 로그인해야 보인다.
3. **긴 페이지 스크린샷 주의** — 스크롤 이어붙이기가 줄을 빠뜨리거나 겹쳐 붙인다.
   심사·홍보용 캡처는 한 화면에 담기게 축소하거나, 찍은 뒤 항목 수를 눈으로 셀 것.
