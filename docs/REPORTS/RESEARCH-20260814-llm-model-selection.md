> 질문: **「사주 상담가로서 말을 가장 잘하고 표현을 잘하는」 모델은 무엇인가.**

한국어 문장의 블라인드 비교**로 한다(§8).

## 1. 왜 우리 «PRO 티어»가 Flash 를 가리키고 있었나

`gemini-3.5-pro` 는 **아직 출시되지 않았다.** 계속 밀리는 중이고 현재 라인업에 없다.
2026-07-12 에 PRO/FLASH 를 둘 다 `gemini-3.5-flash` 로 통일한 결정은 그 시점에선 정확했다.

다만 그 사이 Flash 라인이 두 번 갱신됐고, **우리는 라인업에서 출력 단가가 가장 비싼 모델을
쓰고 있었다**(3.5 Flash 출력 $9/M). 그래서 3.7 로 옮겼다 — 품질·속도·비용이 모두 개선되는
드문 경우라 비교 대상이 아니었다.

## 3. 근거 ① 한국어 실측 — 유일하게 숫자가 있는 자리

Artificial Analysis 다국어 지수(Global-MMLU-Lite) 한국어 순위:

| 순위 | 모델                       | 점수 |
| ---- | -------------------------- | ---- |
| 1    | Claude Opus 4.6 (max)      | 93   |
| 2    | **Gemini 3.1 Pro Preview** | 92   |
| 3~5  | Claude Opus 4.5 / 4.6 계열 | 92   |

⚠️ **이 표를 과신하면 안 되는 이유가 둘 있다.**

1. 이 지표는 «한국어로 된 지식 문제를 푸는 능력»이지 **«한국어를 아름답게 쓰는 능력»이 아니다.**
   우리가 파는 것은 후자다.
2. 110개 모델 중 13개만 실려 있어 **Claude 5 계열·Grok·Flash 계열은 아예 미측정**이다.

읽어낼 수 있는 것은 하나뿐이다 — **한국어에서 실측 상위가 확인된 계열은 Claude Opus 와
Gemini Pro 둘이고, Grok 은 한국어 공개 실측이 없다.**

번역·문체 평가에서는 Claude 계열이 반복적으로 «한국어 최상위군»으로 지목된다(원문의 문체·화자
목소리 보존에서 전문 번역가 선호도 1위). 신위의 «결»을 지키는 우리 요구와 방향이 같은 평가다.

## 4. 근거 ② 아레나 — 표현력의 간접 지표

- **텍스트 종합 1위: Claude Fable 5**(~1525). 뒤에 Claude Opus 4.8·GPT-5.5 Pro·Gemini 3.1 Pro 가
  촘촘히 붙어 있다.
- **창작 글쓰기**: Gemini 3 Pro 가 한때 1위(1493)를 찍었고, 3.1 Pro 는 현재 상위권(~5위).
- **Flash 계열은 이 표의 상단에 없다.** 공식 설명부터가 "complex coding, agentic workflows" 다 —
  문장력은 Flash 가 최적화하는 축이 아니다.
- Grok 4.6 은 지능지수 61로 최상위권이지만 강점이 «지식 노동·에이전트»에 몰려 있고,
  **창작·한국어 표현 쪽 공개 지표가 없다.**

## 6. 근거 ④ 배선 비용 — 코드가 이미 어디까지 준비돼 있나

| 후보       | 어댑터                                 | 전환 작업                                                               |
| ---------- | -------------------------------------- | ----------------------------------------------------------------------- |
| **Gemini** | 기본 경로                              | **상수 1줄**(`GEMINI_PRO`) + 단가표(이미 등록함)                        |
| **Claude** | `generateWithClaude` 존재(SDK ^0.78.0) | 모델 상수 세대 갱신 + 단가표 + `ANTHROPIC_API_KEY` + 크레딧             |
| **Grok**   | **없음**                               | 어댑터 신규(OpenAI 호환이라 어렵진 않음) + 단가표 + 레이트리미터 + 로깅 |

🔴 **thinking 토큰 함정**: Gemini 3.x 는 추론 토큰이 출력으로 과금되고 `maxOutputTokens` 예산을
함께 먹는다. 우리 SDK 는 `@google/generative-ai` **0.24.1(구버전)이라 `thinkingLevel` 제어 API 가
없다.** 다행히 무거운 두 액션(천지인·삼합)은 이미 `maxTokens: 16384` 를 명시해 두었고 나머지는
실측 출력이 기본값 8,192 의 절반 이하라 지금은 안전하다. 다만 **Pro 로 올리면 추론 토큰이 크게
붙으므로 `@google/genai` 신 SDK 이전이 선행되어야 한다.**

## 7. 분석 — 그래서 어느 결과물이 더 좋은가

용도를 나눠야 답이 하나로 모인다.

### ① 고민상담·오늘의 운세·신위 신탁 (짧고, 무료이고, 지연이 곧 UX)

**Gemini 3.7 Flash — 이견 없음(적용 완료).** 상위 모델의 문장력 이득보다 비용·지연 손해가 크다.
신탁은 출력이 44 토큰이고 상담은 245 토큰이다 — **이 길이에서는 모델 등급 차이가 사용자에게
거의 보이지 않는다.** 표현력을 사는 자리가 아니다.

### ② 유료 장문 풀이 (천지인·종합사주·궁합·테마 8종 — 말맛이 곧 상품)

여기가 진짜 결정 지점이다. 셋을 이렇게 본다.

**1순위 · Gemini 3.1 Pro** — 한국어 실측 2위(92)로 **숫자로 확인된 유이한 후보**이고, 창작 글쓰기
상위권이며, 배선이 상수 1줄이다. 원가는 3.7 Flash 대비 +12원/건(테마 풀이 기준)으로 매출의 0.19%.
약점은 preview 딱지(SLA 없음)와 신 SDK 선행.

**2순위 · Claude Opus 5** — 한국어·문체 보존 평판이 가장 두껍고(전문 번역가 선호도 1위 계열),
**어댑터가 이미 코드에 있다.** 약점은 원가 2.2배(83원)와 크레딧·키 준비. Fable 5 는 텍스트 아레나
1위지만 166원/건 + 상담 불가라 **우리 규모에선 과잉**이다 — 최상위 문장이 필요한 자리는
5만냥 상품 정도인데 거기서도 236원이라 굳이 살 이유가 약하다.

**3순위 · Grok 4.6** — **가성비는 셋 중 최고다**(Pro급 지능지수인데 원가는 Flash 수준 25원).
그럼에도 3순위인 이유는 셋이다: ⓐ **한국어 공개 실측이 없다** — 우리 상품은 100% 한국어 서술이라
이건 치명적 미지수다 ⓑ 어댑터를 새로 붙여야 한다 ⓒ 브랜드 톤 리스크 — 우리 신위는 «~합니다» 체의
단정한 상담가인데 Grok 은 상대적으로 자유분방한 톤으로 알려져 있어 규율 프롬프트를 더 세게
잡아야 할 수 있다(추정이며 실측 필요).

### ③ 결론적으로 «어떤 결과물이 더 좋을까»에 대한 답

- **문장 품질의 기대 순위**(한국어 서술): Claude Opus 5 ≒ Gemini 3.1 Pro > Grok 4.6 > Flash 계열
- **비용 대비 만족**: Gemini 3.1 Pro > Grok 4.6 > Claude Opus 5 > Fable 5
- **지금 당장 실행 가능성**: Gemini 3.1 Pro(1줄) > Claude(키+크레딧) > Grok(어댑터 신규)

세 축이 모두 Gemini 3.1 Pro 를 1순위로 가리킨다. **단, 이 결론은 «한국어 지식 QA»와 «영어 창작
아레나»라는 대리 지표 위에 서 있다.** 우리가 파는 것은 그 둘 중 어느 것도 아니다.

## 8. 그래서 판정은 이렇게 한다 — 블라인드 비교

벤치마크는 후보를 3개로 좁혔을 뿐 답을 주지 않는다. 실제 판정은 이렇게만 가능하다.

1. 같은 사주 3인 × 상품 3종(종합사주·궁합·테마 풀이 1종)을 후보 3모델로 각각 생성
2. **모델명을 가린 채** 문장만 나란히 놓고 CEO 가 고른다
3. 볼 것: ⓐ 신위의 말투가 유지되는가 ⓑ 사주 용어를 쉬운 말로 풀어내는가 ⓒ 판정(L2)을 뒤집지
   않는가 ⓓ 금지어·단정 어휘가 새지 않는가 ⓔ 같은 사주에 두 번 돌렸을 때 결이 흔들리지 않는가
4. ⓒ~ⓓ 는 이미 코드가 강제하고 있으므로 실제 승부는 **ⓐ·ⓑ 에서 갈린다**

이 비교 하네스는 반나절이면 만든다. 벤치마크 순위를 근거로 모델을 고르는 것보다
**우리 프롬프트로 뽑은 열 문장을 눈으로 보는 쪽이 훨씬 정확하다.**

## 9. 남은 위험·후속
