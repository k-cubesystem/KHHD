# 결제 시스템 조사 원문 (2026-07-13)

> 구글 플레이 정책 + 국내 운세앱(포스텔러·점신·헬로우봇) + Toss 실무 벤치마킹.
> 실행 기획: `TEAM_G_DESIGN/prd/PLAN-payment-strategy-v1.md`

## 핵심 3줄

1. **웹 전용(현재)이 재무적 최선** — Toss 수수료(0.6~4.3%)만. Play Store 올리면 Google 11~30% 추가.
2. Play Store 원하면 "TWA 안에서 몰래 Toss 아웃링크"는 **정책 위반·앱 삭제 리스크**. 한국 대안결제(Alternative Billing) 정식 등록해도 Google이 26%/11% 가져감.
3. 복채 단일통화는 신뢰↑지만 **벌크 보너스·첫구매 특전 없음** → 전환 최적화 여지 큼. 국내 경쟁앱은 소모재+부분구독 하이브리드.

## Google Play 정책 (확정)

- 가상화폐·구독·콘텐츠 언락 = **Play Billing 의무**. 복채/멤버십/부적/신위/테마/질문권 전부 해당. 실물예외 미적용.
- 앱 내 타 결제수단 유도 금지 (출처: Google Payments Policy).
- 수수료: 표준 30% / 연 100만$까지 15%. 2026-06-30~ 미국·영국·EEA 신규구조(구독 10%+빌링 5%, 외부링크 시 5% 면제) — **한국 적용시점 미정(확인 필요)**.
- 한국 인앱결제법(2021) → 대안결제 프로그램(4%p 할인=26%/11%), 단 PCI-DSS 인증+부정거래 API 의무. 2022년 카카오·리디 아웃링크 강제삭제 전례.
- TWA/WebView 래핑해도 정책은 "앱 내 디지털 콘텐츠 판매"면 동일 적용.

## 국내 운세앱 벤치마크

| 앱       | 구조                                                          | 규모                     |
| -------- | ------------------------------------------------------------- | ------------------------ |
| 포스텔러 | 포스 포인트(리포트)+코인(상담)                                | 860만, 2023 매출 ~99억   |
| 점신     | 실시간 상담(첫3분 무료+사전결제 25%↓)+복주머니/행운패스(광고) | 1900만, 2023 매출 ~829억 |
| 헬로우봇 | 하트 캐시 + 월 26,000원 VIP 구독 하이브리드, 하트 10% 페이백  | 챗봇 타로                |
| 소울톡   | 쿠키 충전 + 신규 10,000원 상담권                              | 전화/채팅                |

- 공통: 오늘의운세·기본사주 무료, 상세리포트/실시간상담 유료. **소모성 재화 주력 + 구독 보조.**
- 서구(Calm/Headspace) = 순수 구독. 사주는 "1회성 고관여" → 소모재가 정석. 해화당 방향 맞음.

## 전환·리텐션 근거

- 첫구매 오퍼 잘 설계 시 전환율 3~5배 (Solar Engine). F2P 재화팩은 5~7단 "6-pack".
- 리워드 광고 시청자 결제전환 4~5배·30일잔존 4배↑ (RevenueFlex).
- 7일 스트릭 = 잔존 최강 선행지표 (Duolingo 14일차 +14%p).
- 가상화폐 자체가 지불의향↑ ("화폐 착시", Cambridge 실험 753명).
- 국내 웹/앱 이원가 관행: 리디 앱캐시 20%↑·웹 유지, 밀리 웹11,900/앱14,900, 라프텔 앱은 수수료 포함가.

## 확인 필요 (자문/실측)

- 2026 신규 수수료 한국 적용시점·법원 최종승인 / 방통위 과징금 확정 / Toss 정기결제 수수료율 / "복채"가 전자금융거래법상 선불전자지급수단 등록 대상인지(폐쇄형이면 예외 가능성) / 아웃링크 배너 허용 문구.
