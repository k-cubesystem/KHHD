# 상담 전문가 포맷 조사 리포트 (2026-07-13)

> 목적: 사주·관상·손금·풍수 각 분야 최고 상담가들의 상담 기술·구조·화법을 조사해
> "우리나라 최고 상담전문가가 운영하는 느낌"으로 ai_prompts를 재작성하기 위한 근거 문서.
> 방법: 분야별 병렬 WebSearch 조사(4 에이전트). 특정 인물의 저작권 표현은 배제하고 방법론만 추출.
> 적용: `supabase/migrations/ai/20260713_prompts_v2_counseling.sql` (시드 마이그레이션)

---

## 공통 발견 — 4분야를 관통하는 상담 원리

1. **정해진 판독 순서(flow)가 권위를 만든다** — 분야마다 표준 순서가 있고, 순서 자체가 "전문가답게 들리는" 뼈대.
2. **관찰 재진술 → "맞다" 반응 → 신뢰 → 미래 해석** — 확인 가능한 사실을 먼저 정확히 짚은 뒤 해석으로 확장. 단 AI 적용 시 실제 데이터(원국·이미지)에 근거한 것만, 콜드리딩식 일반론은 금지.
3. **완충 화법의 공통 구조: 인정 → 재구성 → 통제권 부여** — 흉함의 실재를 인정하되 낙인 대신 시기/개성/에너지로 재해석하고, 할 수 있는 행동을 준다.
4. **처방 없는 부정 진단 금지** — 모든 약점 언급은 "오늘부터 실행 가능한 행동 + 기대 효과"와 짝을 이룬다.
5. **희망 프레임으로 마무리** — 사주(다음 대운), 관상(관상불여심상), 손금(변하는 손금), 풍수(이사 없이 보완) 각자의 논리로 "바뀔 수 있다"로 닫는다.

## 1. 사주 (명리)

### 상담 구조

문진(고민 파악) → 원국 해석(일간 중심 기질) → 대운·세운 흐름(인생 곡선) → 시기 특정(구체 연도) → 개운법 처방

### 핵심 기법

- **과거 검증 후 신뢰 획득**: 원국에서 드러나는 과거 성향·패턴을 먼저 짚어 "맞다" 반응 유도 후 미래로. (원국 데이터 근거 필수)
- **전문용어는 번역과 함께**: 십신·격국·용신을 정확히 쓰되 즉시 현대어 재번역.
- **완충 3단**: ①재해석(흉살=응축된 에너지) ②조건부 전환(이 조건에선 강점) ③시한부 프레이밍(이 구간만 지나면).
- **시기 특정**: 대운 전환 해, 결핍 오행이 들어오는 해, 형충회합 해 → 구체 연도. "언젠가/조만간" 금지.
- **개운법 6축**: 오행 보완(색·방향·음식) / 과기운 덜기 / 생활 리듬 / 인간관계 정리 / 공간 / 언어 습관.

## 2. 관상

### 상담 구조

삼정 총론(인생 3단계 강약) → 오관 정밀(눈·코·입·귀·눈썹) → 십이궁 각론(관심 영역) → 심상(心相) 총평. 십이궁 단독 판단 금지, 교차 검증.

### 핵심 기법

- **구체 관찰 선제시**: "눈꼬리가 살짝 처졌다"급 해부학적 구체성 → "맞다" 반응. 이미지에 없는 특징 날조 절대 금지.
- **단정형 금지, 추측형 어미**: "~로 해석되기도 합니다 / ~한 경향이 있습니다". 특징→결과 서술형 완충.
- **관리 가능 프레임**: 사주불여관상 관상불여심상 — 얼굴은 타고나도 인상은 표정·말투·자세·마음가짐으로 바뀐다.
- **처방 카테고리**: 미소 습관 / 말투 부드럽게 / 자세 교정(턱 괴기·엎드려 자기 금지) / 눈썹 정리 / 심상 다스리기.

## 3. 손금

### 상담 구조

주동수 확인(왼손=선천, 오른손=후천) → 생명선 → 두뇌선 → 감정선 → 운명선 → 보조선(태양·결혼·재물) → 양손 비교 → 통합 서사 + 조언.
정체성: "사주=어떤 사람인가, 손금=지금 어떤 상태인가" — 즉시적·현재진행형 톤.

### 핵심 기법

- **관찰 재진술 → 해석 2단 화법**: 선의 길이·깊이·갈래를 한 문장 되짚은 뒤 원인-결과로 해석.
- **완충 4단**: ①사실 인정 ②낙인 배제("나쁜 게 아니라") ③시기/개성/신호 재해석 ④다음 단계 연결.
- **변하는 손금 희망 프레임**: 선천/후천 구도 자체가 근거 — "오른손이 이렇다는 건 앞으로 또 바뀐다는 뜻".
- **처방 3단 구조**: 손금 특징 → 실행 행동 1가지 → 그 행동이 만들 변화.

## 4. 풍수 (양택)

### 상담 구조

양택삼요(門·主·灶) → 현대 4단계: 현관(삼견·삼불견) → 거실(기의 중심) → 침실(어둠·침대 방향) → 주방(수·화 조화). 방위는 동사택/서사택 정합 판단.

### 핵심 기법

- **첫 문단에 콕 집기**: 가장 눈에 띄는 문제/장점 하나를 즉시 정확히 → "진짜 볼 줄 안다". 일반론 시작 금지.
- **완충 3단**: 완곡한 명명("기운이 균형을 잃은 상태") → 버텨온 것 인정 → 즉시 처방 연결.
- **"이사 없이/큰돈 안 들이고" 선제 전제** 후 처방: 가구 재배치·색·식물·조명·소품. 비보(裨補)는 쉬운 풀이 병기.
- **불안으로 끝나는 답변 금지**: 마지막 문장은 항상 희망·실행 가능성.

## AI 프롬프트 반영 체크리스트 (18)

### 사주 계열 (haehwajigi_master, saju_analysis_v2, cheonjiin_analysis)

1. 상담 flow 강제: 도입 공감({{userContext}}) → 원국 → 대운/세운 → 현재 위치 → 개운법. 산문 흐름 속에서 순서 유지.
2. 시기 특정 의무화: 구체 연도 구간 + 다음 전환점 연도 명시. 모호 표현 금지.
3. 완충 3단 명문화: 실재 인정 → 현대적 재구성 → 시기 한정 + 대응 행동.
4. 개운법 6축 중 최소 2개를 오늘 실행 가능한 행동으로. 추상적 위로 마무리 금지.
5. 원국 근거 과거 패턴 선제시(신뢰 도입부). 데이터 근거 없는 적중 진술 금지.

### 관상 (face_reading)

6. 삼정 총론 → 부위별/오관 정밀 → 종합 순서로 서술 전개.
7. 부정 특징은 추측형 어미만 ("~로 해석되기도 합니다"). 단정형 금지.
8. 흉상 언급마다 관리 가능 처방 1개 이상 짝지음 (표정·말투·자세·눈썹).
9. 오프닝은 실제 이미지의 구체 특징 재진술. 없는 특징 날조 금지.
10. 마무리 고정: "관상불여심상 — 인상은 오늘의 표정과 마음가짐으로 바뀐다".

### 손금 (palm_reading)

11. 판독 순서 고정: 생명선→두뇌선→감정선→운명선→보조선.
12. 각 선마다 관찰 재진술 → 해석 2단 화법.
13. 부정 소견 4단 완충: 인정→낙인 배제→재해석→다음 단계. "불행/흉함" 어휘 금지.
14. "손금은 변한다" + 선천/후천 구도 필수 포함.
15. 각 해석 뒤 행동 1개 + 기대 변화 1문장. (수치화 마케팅 수사 금지)

### 풍수 (fengshui_analysis)

16. 진단 순서 현관→거실→침실→주방 + 단계별 구체 관찰 포인트. 첫 문단 콕 집기, 일반론 시작 금지.
17. 흉 배치는 같은 문단에서 원인→즉시 처방 1~2개로 종결. 저비용(재배치·색·식물·조명) 우선 최소 2개.
18. 전문용어 즉시 풀이 + 마지막 문장은 희망·실행 가능성 ("불안 종결 금지"). 사주 오행 연계 해석은 해화당 자체 로직임을 명시.
