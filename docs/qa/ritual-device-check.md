- [ ] **신당 방 배경이 화면 절반가량**(46dvh)을 차지한다 — 작으면 「무대 지배」 설계 미달
- [ ] 배경이 안 뜨면 그라디언트로 대체되고 깨지지 않는다
- [ ] 향 연기가 **위로 흐르며 옅어진다**(끊기거나 튀지 않는지)
- [ ] 불씨가 **은은하게 밝아졌다 어두워진다**
- [ ] 소원 갈래 **7종**: 식구들 무탈 · 건강 · 재물 · 학업 · 인연 · 사업 · 그 밖의 소원

- [ ] 입력한 문장이 **서버로 가지 않는다**(설계상 저장 안 함 — 새로고침하면 사라지는 게 정상)

- [ ] 🔴 **복채 잔액이 30 늘었는지** (상점·지갑에서 확인)
- [ ] 다시 들어가면 **장부로 직행**하고 향 올리기가 막혀 있다
- [ ] 🔴 **두 기기(또는 두 탭)에서 동시에 향 올리기** → 적립은 **1회만**
